# Self-WSP（0.8B 模型自读自改权重的归因解剖）深度分析

**总表条目**：#154｜arXiv 2611.28833（v1 2026-11-21）｜T2 **[高价值]**（轻评估⑧→**深读坐实**）｜深读批次㉒（2026-11-25，全文 HTML+附录；权重自改线三连之一）

**【一句话】**权重自改线的**归因解剖书**：Qwen3.5-0.8B 读自己的权重提出编辑、带着被编辑的权重继续当解题者兼编辑器——自编辑把 GSM8K 11.8→62.2/MATH500 7.0→32.2（有时只改 16 个参数、+12 轮的一个模型距起点只差 2 个数）；**但全套归因对照显示增益大半来自外环搜索与选择而非「理解」**：编辑位置跟着目录走（目录排序后 62% 编辑落在第一行 layer 0）、数字直接抄刚读的统计量（A_log 均值 −1.979 出现在四个选中模型里）、解释经常幻觉（最离谱的一条是从练习反馈里逐字抄来的「一把椅子 11 美元」）、**同预算随机搜索在 GSM8K 打平自编辑**（32.8 vs 31.9）、**冻结编辑器（编辑器不吃自己的编辑）无任何可辨增益**、GPT-6 的简单编辑被归入随机编辑范围（采样器约 1/1.3 亿才能抽到、但最好单条随机编辑与它同分）。

## 2 机制（§2——接口与外环）
- **一模型两角色**：0.8B（24 层、3/4 线性注意力+1/4 标准注意力）；编辑器态关 thinking、解题态开 thinking；两角色永远用当前权重——**每个被留存的编辑同时改变解题与下一次提议**（字面意义的自指）。
- **读**：318 张量目录（名称+形状）→选定 1-2 张量后见统计量（均值/标准差/行列范数/≤64 个值）+练习题成绩反馈。**与 Takehi 设置的关键差异：GPT-6 有 Python 环境自由分析，本编辑器只见预计算信息**。
- **写**：语法约束 JSON（小模型格式遵循不可靠）；7 种操作（置零/乘/加/填充/重抽/移除方向/短 NumPy 表达式）；重复/整体缩放/无变化即弃。**结果：模型从未用过两个结构化操作（移除方向/表达式），几乎只会乘/平移**。
- **外环纪律**：三份数据切分（练习=训练带答案/验证=训练但永不给编辑器/测试=标准测试集只在最后用一次）；两批不相交练习题上「合计提升且两批都不变差」才留存；**验证集只在轮末评分选模型、从不回喂**；Top-1/2/3=12/24 个 run 里验证增益最大者（最好情形）；**预指定的抽查 run（spot-check）永不参与选择=普通情形的诚实代表**。
- 双接口：shuffled（目录乱序/32 题/留 1 题增益）vs ordered（按层序/128 题/留 ≥3 题增益）。

## 3 主结果核验（Table 1 逐行）
- **22/24 选中模型显著超原模型**：ordered 接口 GSM8K 11.8→61.0（Top-1）/MATH500 7.0→24.2-24.7；continued：GSM8K 62.2/MATH500 最高 **32.2**（距 GPT-6 的 66.9/49.5 尚远；MATH500 上 GPT-6 仍遥遥领先）。
- **极小编辑**：24.2% 的 MATH500 模型只改 16 个数（第一线性注意力层 A_log=遗忘速度）；59.9% 的 GSM8K 模型改同层 32 个数；**一个 +12 轮模型距起点只差 2 个数再 +6.8 点**；无选中模型改动 >0.2% 权重。
- **抽查 run vs 选中 run**：ordered 接口抽查平均 GSM8K +24.7/MATH500 +7.7——**远低于选中的 61/24**（选择效应本身贡献巨大）。
- **典型轨迹停滞**：12 个八轮 run 里留存编辑**平均不改变验证精度**；抽查 run 在 +4 后基本不涨、一个从 28.4 一路掉到 23.4；「轮数给外环更多抽签机会，**但模型作为编辑器并没有变好**」。

## 4 深读金子（摘要外）
- **金子① 归因对照三连（本篇的方法论主贡献）**：① **随机搜索同预算打平**（GSM8K 32.8 vs 31.9；MATH500 同预算随机找不到任何改进、多 70% 预算才到 13.6——自编辑提案**温和优于**随机但「不是因为知道为什么」）；② **冻结编辑器对照**（编辑器永远用原始权重、只有解题者被改）：**与另外两者无差**——「让编辑器自己也被编辑没有可辨收益」=对 #102 冻结设计的事后正名+对「递归自指增益」的证伪读数；③ **GPT-6 简单编辑=随机编辑**（置零 256 列在随机编辑空间内、22.0/13.8 分=最好单条随机编辑同级；**GPT-6 更强的编辑（从激活算方向移除）在采样器能力之外**——真懂与运气的分界线画在这里）。
- **金子② 「幸运编辑」的完整解剖（Figure 3）**：最佳 GSM8K 提案=选 layer 0 前两张量、把第一张量乘上第二张量的均值 −1.979、再给第二张量加同一数——**解释声称「撤销 −1.979 的缩放」但撤销应该除以它、编辑却再乘一次：解释与操作自相矛盾**；结果 12/20→78/87 答对、测试 61.0%。**「会改」与「知道自己在改什么」完全脱钩的最干净标本**。
- **金子③ 增益的病理学解释（为什么小编辑走这么远）**：**Qwen3.5-0.8B 的 90% 题目因思考重复在 32k token 内完不成**；被编辑改对的答案几乎全是「原本没做完的」；全部模型上精度与未完成率近似线性；**任何打破重复的编辑都能大涨**——且同文引证解释了 GPT-6 改不动 Gemma 3 270M（很少重复的模型）与 #102 线（修「重复循环」正是 Keel 的第一案例）。**62.2% 的 GSM8K 大半是「不再卡壳」而非「会数学」**。
- **金子④ 目录顺序效应（62%→layer 0）**：乱序目录时编辑按目录份额分布；按层排序后 62% 有效编辑落在 layer 0（目录第一行）——**首提案轮就出现（还没看到任何结果）**；15 个 ordered 选中模型全部编辑 layer 0 A_log、9 个 shuffled 选中模型无一编辑它。**编辑位置=接口产物而非权重理解**——对整条权重自改线的评测设计警告（接口本身在引导编辑）。
- **金子⑤ 解释幻觉的测量**：9-28% 的编辑数值=刚读的统计量（均值/标准差/范数）；解释多为空/描述错块/无关（极端案例：「一把椅子 11 美元」逐字抄自练习反馈里解题者的回答）。
- **金子⑥ 方法学处方（对全线的规约）**：「这条路的进展最好**对照同接口同预算的随机搜索来量、并随附抽查 run**」——直接给 #101/#102/#107/#154/#155/#156 一整套后续的验收标准；随机基线在超参优化与 RL 里本就是强基线（Bergstra & Bengio 2012/Mania et al. 2018）——**权重自改线首次有了自己的对照规范**。
- **金子⑦ 留存门槛的选择代价**：>40% 留编辑的轮次降低验证精度（shuffled；ordered MATH 仍有 1/3）——练习分估计的长尾误差+「只看练习分决定留存」的外环**必然**留下一部分运气分（连 #91 PACE「分数涨就提交在 p-hack」的权重版）。

## 5 库内连线
- **#103 Resolution Hypothesis**：金子①+②=「选择>提议」在权重编辑域的最完整实例化（「大增益来自少数幸运提案，**是外环留下了它们**」——论文原话）；金子⑦=留存门槛的 #91 同款。**#103 的域外预言被独立坐实**（该文未引 #103——两文同期互不知晓=同结论双源）。
- **#102/#156（同线对照/矛盾裁决）**：轻评估⑧标注的「矛盾对」在此解决——#102「小模型改坏自己」与本文「0.8B 大幅自改」并存：**0.8B 的成功=外环选择+易修病理（重复）**，非「理解」；且金子① 冻结编辑器对照**反向支持了 #102 的冻结设计**（被编辑的编辑器没有增益）；#156 Self-Upgrading 的 self-examiner=把外环质量做成结构，与本文「外环做主功」互补解释。
- **Takehi et al. (2026)（watch 候选锚定）**：本篇坐实其为可引用出版工作（WSP 论文）；GPT-6 强编辑（激活方向移除）在随机空间外=**「真懂」的候选分界**，弱编辑在随机空间内。
- **#106 Feedback-Free**：反面对照——本文的编辑器也无「反馈理解」（解释幻觉=无反馈解释漂移的权重版孪生），但**外环给了筛选**所以不漂移（无信号必漂 vs 有选择信号可留——反馈信号质量谱系的权重编辑节点）。
- **#151/MGM**：金子⑦ 留存门槛=acceptor；MGM 诊断压缩=从 evidence 侧提高候选质量、本文随机对照=从归因侧证明候选质量的来源——两文同一「编辑器 vs 外环」记账问题的两个面。
- **#107 Keel**：金子③ 病理学（重复循环）与 Keel 首案例同靶——**「打破重复」是权重编辑线反复出现的最大单点收益**。

## 6 诚实边界
单一 0.8B 模型+两个数学基准；**重复思考是「异常易修」的病理**（自认：会延伸到多深失败模式未知）；外环用练习题参考答案=**监督式改进**（非无监督自评）；ordered 接口是看过 shuffled 结果后设计的（**事后接口**——目录顺序效应部分是设计产物）；未在 ordered 接口下跑随机搜索；未做目录反转实验直接检验 layer-0 偏好；GPT-6 对比只是指示性（工具/反馈/预算都不同）；无 venue、v1。

## 7 遗留（深读新设）
- ordered 接口下的随机搜索对照（当前「随机打平」结论只对 shuffled 接口成立）。
- 目录反转实验（layer-0 偏好因果检验）。
- 打破重复之外的病理（Gemma 270M 不可改的负例做对照起点）。
- 金子⑥ 处方的落地：给 #101/#102/#107 线补「随机基线+抽查 run」复算。
