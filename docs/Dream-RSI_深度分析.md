> **一句话**：把"发现历史"从静态上下文升级成**回放模拟器**（replay simulator）——元策略改进从"又贵又慢的在线试错"变成"零执行成本的离线 dreaming"，回放分还带**不劣下界**；AlphaEvolve 谱系在元层面的机制升级，Google/DeepMind 官方入场 L3。

## 1. 问题定义：元层探索的两难

- **两难**：固定探索策略无法随搜索空间扩张自适应（反复把算力砸向无效方向）；在线优化策略又卡在元层瓶颈——评估一个"探索策略"好坏要观察它塑造的整个后续发现过程，**反馈又贵又慢**（长程 rollout 才出信号）+ 元策略空间巨大（多数候选不值得在线试）。
- **关键洞察**：已完成的发现历史天然是一台模拟器。历史组织成**发现树**（每节点=一次尝试：工作区快照+产物+评测诊断+分数），备选策略只需在树上选不同分支/顺序/并行组/停止点——**所有结果已存档，评新策略只读记录、零执行成本**。类比 model-based RL / Dreamer 家族：历史=环境模型，"dreaming"=在模型里练策略。

## 2. 方法（三阶段闭环）

1. **Online Explore**：当前策略（可执行代码）引导固定 coding agent 扩展发现树；动作=从"根∪叶"选 ≤W 个节点的并行批。策略代码全程固定，agent/评测器不动。
2. **Construct Replay Simulator**：把历史树转成可复用回放池；回放是确定性的（返回已记录子节点，不生成新结果）。
3. **Dreaming-based Policy Improvement**：LLM 策略开发 agent 逐版改策略代码（M 版），每版在全部历史树上回放打分；回放分 **V = max 分数 − β₁·N（执行成本）+ β₂·N/k（并行奖励）**；选优部署上线，新历史再扩充模拟器池——闭环。

**两个方法学要点**：① 选优集含当前策略，故**回放分单调不降**（V(m\*)≥V(0)）——"不劣保证"但只在回放分布内成立，在线无保证（论文如实区分）；② 只改探索策略代码这一层（轻量编排：分支/并行/停止），底座模型、评测器、接口全冻结——自指涉深度刻意收窄，换来可审计。

## 4. 五个可引用结论（证据强度：受控实验，多域）

1. **历史复用方式分层（最重要）**：§5.1 受控对照——把历史抽象成语义指导注进 prompt，**两种范式下都一致劣于**回放模拟器用法；解释=长程发现里强语义先验**过度约束搜索空间、扼杀多样性**。这是"经验怎么复用"（Q1）第一条正面对比读数：**回放 > 语义总结**。
2. **元级反馈成本可降 1.7×–162×**（Q1 信号成本问题的第一条机制解法）：一次昂贵在线 rollout 支撑数千次零成本策略评估——历史从"沉没成本"变"复利资产"。
3. **策略学出资源自适应行为**：§5.2——进展期自动省算力（110→50 次尝试）、平台期自动加码，与进一步增益重合。与 #53 的 advantage collapse 检测（plateau→信号塌缩→换方向）是同一现象的两种处理：一个自动调预算、一个显式换任务。
4. **元层 RSI ≠ 能力自增**：改的是"怎么探索"不是"模型本身"——自生成燃料用在 meta 层（历史→模拟器），**不与 #52 的"自生成经验收敛"批评冲突**：改进对象是策略代码且有回放兜底，烧的是已花掉的沉没成本。给 Q1 燃料假说补一条：**历史回放是自生成燃料里唯一免费的**。
5. **诚实的边界**：回放评估有支撑集偏置——策略只能在已记录分支上被评（off-policy on support），分布外行为无信号；论文未量化此偏置（遗留）。

## 5. 与本库的接口

- **Q1（复利/收敛）**：结论 1/2/4——燃料来源假说新增"历史回放"分支；元层反馈成本问题的首个机制解。
