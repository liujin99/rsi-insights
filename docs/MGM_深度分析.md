# MGM: Mendel Gödel Machine（比较进化的自改代码 agent）深度分析

**总表条目**：#162｜arXiv 2608.07645（v1 2026-08-07）｜T2（轻评估⑧→**深读坐实**）｜深读批次㉑（2026-11-25，全文 HTML+附录；**与 #151 Gödel Forest 配对读**——#151 深读时追的「trace 共享败法出处」本尊）

**【一句话】**XGM 谱系（DGM→HGM→MGM）的第三步，改的不是「选哪个节点扩展」而是**「给编辑器什么证据」**：此前每次自改只看一条失败轨迹——MGM 按孟德尔控制遗传原则把自改做成**诊断过程**：**clonal mutation**（单轨迹基线）/**reaction-norm mutation**（同基因型跨任务轨迹对照——复发失败模式=基因级缺陷而非任务意外）/**cross-lineage hybridization**（异谱系同任务对照——行为差异=可迁移技能；不剪贴代码，目标 agent 自己提炼适配）。加性适应度地形模型下**理论证明+蒙特卡洛模拟**双坐实：比较证据提高有效修复概率的机制=**诊断压缩**（编辑器没变强，候选缺陷集变小变干净）；同预算 200 评测下 Polyglot 50.8→93.2（HGM 77.9）、SWE-V 68.3→78.3（73.3），**跨基准 HGM 负迁移（13.3）vs MGM 正迁移（26.7）**、跨底座迁移更强。

## 2 机制（§3-§4——三算子+失败池+诊断压缩理论）
- **三算子（按可用证据条件触发）**：Φ_CM=单失败轨迹（档案小时兜底）；Φ_RM=同 agent ≥m_RM 条轨迹、其中含失败——要求编辑器找**跨轨迹复发/对照的行为模式**并做通用改进；Φ_CH=两谱系碰过同一任务且未双解——失败方为目标、用参考方轨迹做对照（参考也失败=互补失败模式分析；参考解了=基因型差异当矫正信号）；**杂交不拼接源文件**——目标 agent 自己从参考轨迹提炼可迁移行为并适配自己代码库（鼓励「真改进」而非任务特化行为）。子代挂在主谱系上。
- **失败池 P_t+β_fail 加权采样**：凡暴露过失败的任务进全局池，未来评测采样对池内任务加权——**评测预算集中在已知能暴露弱点的任务上**+刻意制造跨谱系任务重叠（Φ_CH 需要共享任务）——**不花额外评测就提高受控对照的可得性**。
- **诊断压缩理论（Prop 1，金子级）**：加性地形（L 位点二值基因型、任务=k 位点子集、成功=子集内无错）下，有效修复概率 p_f=s·Pr[候选位点真错]。CM 的候选集=失败任务触碰的全部位点 R_τt；**RM=两任务区域交集（更小）；CH=参考方成功把非因果位点滤掉**——所以 p_f^RM>p_f^CM、p_f^CH>p_f^CM。**一句话机制：比较证据不是让编辑器更强，是削减诊断不确定性**。蒙特卡洛：ρ=1（无诊断优势）时 MGM 塌回 HGM 行为=**受控归因**（增益来自证据质量不是别的）；ρ 越大增益越大、d₀ 越小优势越显。
- **成本纪律**：三算子同成本（c_CM=c_RM=c_CH=c_φ）+只用档案里已有轨迹（**零额外评测**）——所有对比在等预算下跑。

## 3 主结果核验（§5 逐行）
- **主表（Qwen3.6-35B-A3B，200 评测+24 扩展，同祖先起点）**：SWE-V 68.3→HGM 73.3/**MGM 78.3**（+10.0）；Polyglot 50.8→77.9/**93.2**（+42.4）；平均 59.6→75.6/**85.8**（+26.2）。token 成本同量级（增益非买来的）；时间同量级（96.11h vs 93.02h）。全 225 题 Polyglot 上 MGM **93.3% 超 GPT-5、参数少 ~117×**。
- **跨基准泛化（Polyglot 进化→冻结→零样本测 SWE 变体）**：SWE-bench Pro 16.7→**26.7**（**HGM 掉到 13.3=负迁移**）；Multilingual 41.7→**55.0**（HGM 43.3）——**MGM 的改进不特化到源基准失败模式、更接近可复用工程工作流**。
- **跨底座迁移（SWE-V 上进化→换推理底座）**：DeepSeek-V4-Flash 50.0→HGM 60.0/**MGM 66.7**；V4-Pro 45.0→70.0/**75.0**；双底座平均 47.5→65.0/**70.8**；Polyglot 全集+V4-Pro=**96.89%**——「小档进化、强档放大」的复用路线证据。
- **消融（Polyglot-60）**：去掉 Φ_RM 或 Φ_CH 都明显掉；**Φ_CH 更关键**（跨迭代保留复用进化信息）；训练时长同量级。
- **F.2 大编码模型反而弱（金子级反直觉）**：Qwen3-Coder-Next-80B（更大+编码特化，但通用推理弱：GPQA −11.51/HMMT −20.49 vs Qwen3.6-35B）→ MGM 只到 41.7（同设置 35B 到 61.7+）。**「编辑是编码操作，但决定改什么=诊断+抽象问题」——编码特化模型产得出合法自编辑、产不出更好自编辑**；且**比较证据只有在底座能推理它时才有用**（RM/CH 让诊断更信息密集、也更推理密集）——**backbone 选择按诊断/推理能力不按编码分**。

## 4 深读金子（摘要外）
- **金子① 诊断压缩（Prop 1）**：比较证据→候选缺陷集交集/过滤→真错位点密度上升——**proposer 侧解决「认不出好东西」的办法：不改选择器，先改证据让候选集更干净**（连 #103：选择瓶颈的编辑器侧镜像——同一问题的两端；#101 Holm 门槛是 acceptor 侧解、MGM 是 evidence 侧解）。
- **金子② F.2 backbone 选择读数**：自改进上限由「从轨迹推断失败机制」的通用推理能力决定——**编码分不能预测自改进收益**（连 #102/#156 的规模阈值读数：不是参数量也不是专项分，是诊断推理档）。
- **金子③ 失败池 β_fail=弱点引导的评测侧形态**：评测预算主动偏向已知暴露弱点的任务+刻意造重叠——**「便宜的验证」不只在单次评测便宜，还在「每次评测的诊断信息量」上贵得其所**（连 #52 弱项引导/#105 观测面进化/#151 诊断门控——同一思想的三处落地）。
- **金子④ F.3 泛化性操作判据**：不看措辞是否宽泛，看「是否从训练实例抽象成可复用程序」——MGM 技能点聚成紧凑区（测试契约提取/API 契约遵守/实现前验证），HGM 点散（碎片化干预）——**语义可视化当泛化性量尺**（连 #106 先验外含量审计：另一种「什么才是真可复用」的测量）。
- **金子⑤ H.1 三编辑谱系（最佳 agent 解剖）**：initial→#2（CH：read-first 指令）→#9（RM：两阶段 contract_plan JSON 提取+清单自审）→#16（RM：run_tests() 测试驱动验证环≤5 次）——**从 prompt-only 代码生成器进化成契约引导+自审+经验自纠的 agent**；SWE-V 侧=code_path_trace+溯源回调（记录看过的文件）+diff 最小化过滤器（抑制投机广撒网）——可复用工作流的具体标本。
- **金子⑥ 可遗传编辑的持久化风险（伦理节）**：错误/恶意自编辑**在后代中持续存在**——连 #98 error reproduction（记忆层）的组织层同构：进化系统的档案=错误的复利器，隔离容器+只读挂载是底线工程形态（连 #104 独立 Benchmark Job——结构性隔离家族）。
- **金子⑦ ρ=1 塌回基线=受控归因范式**：诊断优势置零时方法退化为 HGM——**「增益来自主张的机制」这一步的实验证明**（连 #154 Self-WSP 的随机搜索对照：同一种「归因自查」的两个方向——MGM 证明增益来自证据、Self-WSP 证明增益未必来自「自己」）。

## 5 库内连线（配对读核心）
- **#151 Gödel Forest（配对本尊，三点修正/互补）**：① **修正 #151 文档的判读**——「MGM 的 trace 交换=context 饱和」应精确化为：MGM 实际是**受控两两对照**（每次编辑最多 2 条轨迹），Gödel Forest 批评的是**朴素全 trace 广播**；② **两条线是不同协调层级的互补解**：Gödel Forest 管**跨树广播**（K 棵树的协调带宽→100 token 结构化教训+leaderboard），MGM 管**档内编辑证据质量**（2-trace 对照提单步修复率）——「协调什么」不同（教训 vs 证据），不是优劣关系；③ **共享失败池思想**（MGM β_fail 弱点加权 vs #151 负面教训=归纳护栏）与「单个体深挖死窄路、朴素并行重复踩坑」的同起点诊断——**配对结论：多体 RSI 的两条正交轴=体间协调带宽（#151）+ 单步证据密度（MGM），预算固定时兑着花**。
- **#103 Resolution Hypothesis**：诊断压缩=proposer 侧的识别解法（提高候选池真改进密度）；F.2=识别瓶颈在编辑器层重现（诊断推理弱则证据白给）——**#103 的「让真改进可检测」在 MGM 里换成「让候选集可诊断」**。
- **#154 Self-WSP（同周矛盾对延伸）**：金子⑦ 的 ρ=1 对照 vs Self-WSP 的随机搜索对照——两种归因自查方向相反（MGM 证明「增益来自证据」/Self-WSP 质疑「增益来自自己」）——**归因对照实验正在成为权重/代码自改线的标配纪律**。
- **#102/#156 规模阈值线**：金子②（诊断推理≠编码分）与「只有 27B 做得到」同族——**自改进的规模档由推理诊断能力定，不由参数量/专项分定**。
- **#98 error reproduction**：金子⑥（可遗传编辑的持久化风险）=组织层标本。
- **#52/#105/#151**：金子③（失败池=弱点引导的评测侧形态）。
- **#39/#62**：G.2 的离线进化+运行时适应互补=基建侧「训练时/推理时」分工的 agent 版。
- **姊妹库 data-mixture-insights**：**实验间比较证据的结构学**——同一配方跨域对比（RM 类比：配比 A 在多域的失败模式对照=找「配方级缺陷」vs「任务意外」）+不同配方同任务对比（CH 类比：同基准上配方差异当矫正信号）+失败池加权（把评测预算花在已暴露弱点的组合上）——对 N=1-2 runs 的实验设计直接可搬（已递接口文档追注⑤）。

## 6 诚实边界
**历史依赖**（自认：档案小/任务重叠稀疏/失败未积累时无对照可用、退化为单轨迹基线——失败池只能缓解不能前置创造对照）；**证据质量≠编辑质量**（编辑仍由 LLM 产出，好证据不保证好修改）；加性地形=受控代理模型（自认不捕捉真实 scaffold 全复杂度）；**固定 60 题子集+种子多样性有限**（跨重启方差未测——连 #103 方差纪律：绝对数字打折、方向性结论稳）；编码域限定（非编码 agent 未测）；HGM/DGM 对照为同组前作（谱系内对照而非第三方）；无 venue、v1；Polyglot 全集数字混用 60 题进化+225 题评测口径（已注明）。
