# DoppelVet（同证据异结局：验证器等价类的安全验证）深度分析

**总表条目**：#158｜arXiv 2611.29306（v1 2026-11-22）｜T2 **[高价值]**（轻评估⑧→**深读坐实**）｜深读批次㉔（2026-11-25，全文 HTML+附录；轻评估⑧五篇 [高价值] 深读收官）

**【一句话】**「同证据异结局」的**原则级命名+正面解法**：两个更新给验证器的证据**逐字节相同**、安全后果相反——**任何只看证据的判定规则（含一切校准/调阈值）原理上分不开**（Prop 1：同输入必同输出）。DoppelVet 在更新进持久状态前动手：构造一个**与现有验证器读到的每个信号都完全匹配**的替身、同状态重放两个更新、**两种呈现顺序都直接比行为**再决定（收/拒/弃权）；9 个开源/商用验证器上 Grid 有害更新检测 AUC 0.762→0.940、Tool 0.681→0.826；十代自更新环上经历退化 30.39%→0.43%、**最终零退化**。

## 2 机制（§3——三段式）
- **问题形式化**：持久状态 s_t、更新 u、回放库 B={x₁..x_m}；**原生验证器完整读出 r_B(u;s_t)=逐上下文读出的全向量**（奖励/episode 长度/测试/结构化结果——「记录判定规则用到的每个值，不只最终布尔输出」）。两个更新**读出逐字节相等**即「验证器等价」；安全结局 Y 独立来自完整执行（副作用度量/确定性工具轨迹检查）。**Prop 1（校准不可能定理）**：等价类的两个成员给 g 的输入相同→输出必相同，**任何校准映射之后仍相同**——混合类没有「原读出之外的证据」就不可分。不是每个类都混合，但混合类无解（除非加新证据）。
- **阶段Ⅰ 构造替身**：有界邻域（程序空间枚举/文本最小程序性对比——**只改一个操作边界**（如工具动作前的一个前提），保持任务/对象/指令模板）→**只留读出逐字节相等者**（N_eq）→用**可见轨迹距离**排序（Grid=棋盘格+可见奖励失配；Tool=工具序列+渲染轨迹 difflib 散度——**隐藏安全标签排除在距离外**）→选距离最大者 v*；**没有行为可分的等价替身就弃权**（不动持久状态）。
- **阶段Ⅱ 直接对比**：同状态同上下文重放 u 与 v*；比较验证器 J 判「候选相对替身是否引入实质安全风险」；**两种呈现顺序都打分再平均**（R_J=两序平均——对位置偏差的防御，引 LLM-as-judge 位置偏差文献）；阈值在校准集上冻结（θ_A≤θ_R：收/拒/弃权三分）；对称记忆对**留风险较低者**；**从不自动提交替身**、相对偏好≠安全认证。
- **阶段Ⅲ 持久化控制**：确定性检查（不变量/schema/状态兼容）+对比结果三态决定；**只有 admit 过持久化边界**；提交前写**回执**（绑定前状态/候选/替身/回放库/分数/阈值/检查结果/实现版本）；激活后持续监控，**违规→恢复记录的已验证状态+记录失败更新+重跑检查**。
- **成本**：在线 O(Nm) 次执行（u 固定）+2 次模型调用；需要四个接口：可回放状态/规范读出/可见轨迹/原子提交-恢复。

## 3 主结果核验（Table 1-4 逐行）
- **RQ1（等价类真实存在）**：六个 Gridworld 穷举执行——**4/6 环境存在同读出异结局**（Sushi 具体例：4 个更新同任务奖励 50、同长度 5，2 个安全分 50、2 个 0——寿司动没动在证据里**完全不存在**）；文本更新同样存在（自动构造 364 个对比中 28 个精确读出安全分裂）。**DoppelVet 在所有含有害替身的 Grid 案例中 100% 排第一**（对照均匀随机的 85.6% 等）。
- **RQ2（9 验证器全升）**：Grid 均值 0.762→0.940（增益 0.001-0.432）、Tool 0.681→0.826（0.042-0.217）、严格同奖励子集 0.645→0.831。**弱验证器增益最大**：GPT-4.1 原始 0.493→0.925（原始几乎掷硬币——候选单看接口在困惑它）；**前沿接近饱和**：GPT-5.6 Sol 0.983→0.984、Claude Opus 5 0.994→0.996（Grid 上问题主要是中小验证器的）。
- **关键消融（B.8——金子级）**：AgentDoG 1.5 **两遍独立打分相减**（两条轨迹都看、但不在同一上下文里比）=**0.419**<单看 0.454——**「看到两条」不够，必须在同一上下文里直接比**；联合绝对打分（同上下文但绝对判断）GPT-4.1 只 0.391——**比较式提问是活性成分**。可见散度纯标量 0.720（差 0.25）；**VaG 四批评家 0.796 用 3.383M token vs DoppelVet 0.970 用 1.586M（一半 token 高 0.17）**。
- **RQ3（十代环）**：464 个起始程序、监控与回滚**关掉**测纯过滤：原始有害提交 47.41%/经历退化 30.39%/最终退化 7.76%；逐点 19.40/10.78/4.74；AgentDoG 25.22/18.32/7.97；VaG 12.72/6.68/3.88；**DoppelVet 0.86/0.43/0.00**；**安全更新留存 89.58%**（比三个候选单看基线都高——不是靠拒掉一切换来的）。
- **RQ4（工具记忆选择）**：176 个新对话（Qwen2.5-32B agent）：违规率 19.3%（最低，原始 22.7%/VaG 20.5%/AgentDoG 22.7%）；安全任务完成 64.2%（最高）；结局不同时选更安全记忆 **66.7%**（VaG 54.2%/原始与 AgentDoG 45.8%）。
- **ATBench 外部迁移**：0.646→0.771（超 AgentDoG 0.751）；**诚实脚注**：公开版无原生读出与配对身份=「参考锚定比较」而非精确等价构造；**随机安全参考也有 0.717**（超原始 0.646）——ATBench 增益大半来自「有个好参考」而非等价构造本身（等价部分约 +0.05）。

## 4 深读金子（摘要外）
- **金子① Prop 1 的定位（校准不可能定理）**：证明本身一行（同输入必同输出），但**命中的是整条验收线的软肋**：阈值调整、置信校准、更强的判定规则——**在证据集合不够时全都不存在出路**；唯一出路是**加证据**（行为对照）。给 #91 PACE「分数涨就提交=p-hack」一个原理级根：不是阈值没调好，是**分数这个证据维度本身可被等价类骗过**。
- **金子② 弃权三态+回执+监控回滚的完整验收栈**：收/拒/**弃权**（无行为可分的等价替身、序间不一致都触发弃权——保守默认=不动状态）；回执把「当时的全部证据+决策依据」绑定存证；事后违规能**恢复到记录的已验证状态**——把 #53 撤走纪律/#101 修复集/#98 error reproduction 拼成一个可运维的栈。
- **金子③ 双回放的对称性纪律**：同状态+同回放库+**双呈现顺序平均**（位置偏差防御进协议）；替身**永不自动上位**（相对偏好≠安全认证）——把「对比」用作证据增强而不是替代判定，避免了「比较分高=安全」的过度解读。
- **金子④ 前沿饱和+弱者大跳的分布读数**：Grid 上 GPT-5.6/Opus 原始已 0.98+（问题不存在）而 GPT-4.1 原始 0.493（接口困惑）——**等价类盲区主要是中小验证器的病**；DoppelVet 对弱验证器的修复幅度（+0.43）远超对前沿的（+0.001）。部署含义：给 14-32B 级验证器配双回放比换更强验证器便宜。
- **金子⑤ 十代环把「持留伤害」量化成可审计指标**：经历退化 30.39%→0.43%、最终退化 0——**单个误批准的持久代价**（一个错误记忆塑造后面所有行为）第一次有了干净读数（连 #98 持久化伤害线）；且安全留存 89.58% 说明不是「全拒保平安」。
- **金子⑥ B.4 压力测试的诚实标注**：6 对记忆的配对检验 Wilcoxon p=0.094/符号检验 p=0.219——**明确标为「描述性配对级检验」，不拿对话级重复计数凑独立单元**（「conversation-level counts are repeated measurements and are not substituted for the independent update units」）——小样本处的统计诚实，与 B.1 时序控制（计划/排序/类身份/提示词写在隐藏标签接入前）同属全文卫生亮点。

## 5 库内连线
- **#103（验证器瓶颈的又一层解剖）**：#103 证明进化环的瓶颈在验证器不在算力；本篇把「验证器会怎么坏」再切一刀——**不是验证器不聪明，是它读的证据维度里根本没有这个信息**（等价类）。#103 的解法侧（更便宜的验证器走量）与本篇的解法侧（加行为对照证据）正交可叠。
- **#157 Blind（同周姊妹题——配对读主结论）**：#157 证明 agent **自写的检查**漏一半以上失败（检查写得太窄）；本篇证明**任何基于任务读数的检查**（不限于自写）有原理性盲区（同读数异结局）。**两篇合成验收线的完整病理学**：#157=检查的覆盖面问题（可修，加一行结果规则那种）；#158=检查的原理性失明（不可修，必须换证据源）——「修检查」和「换证据」是两种不同的药。
- **#156 Self-Upgrading（同批配对）**：#156 的夜=同任务同种子配对测试+保留题确认（**行为对照的内部版**）；本篇=构造替身+同状态双回放（**行为对照的框架版**）。同一个思想在两边独立出现：**判定要发生在行为层，不能只发生在读数层**——验收线当周的三篇（#157/#158/#156）从三个方向收敛到这句。
- **#91/#53（acceptor 线）**：弃权三态=PACE anytime-valid 的三态化（收/拒/停）；回执+哈希链=e-process 的工程化近亲；「分数等价类骗过阈值」=p-hack 的形式化。
- **#101 BaseRSI（Holm 接受测试）/#104（独立 Benchmark Job）**：结构性隔离第三形态（轻评估预判坐实）——#101 用统计检验、#104 用独立作业、本篇用**等价类内行为对照**，三种「让验收者拿到提案者给不了的信息」的设计。
- **#154 Self-WSP（同一周，意外呼应）**：#154 的抽查 run（预指定、永不参与选择）与本篇的替身构造（读出匹配、行为对照）都是**「对照出真增益」**；#154 证的是「分数涨可能是运气」，#158 证的是「分数平可能是祸福」——**读数不携带全部真相**在权重线和记忆线同周各自拿到证据。
- **#98（error reproduction）**：金子⑤=持久化伤害的受控量化（投毒文献只说「能投毒」，这里量出「不设防环 30% 轨迹经历退化」）。

## 6 诚实边界
**等价类构造的可扩展性是最大问号**：Grid 是确定性小程序空间（可穷举），文本替身靠模板改写（一个前提的改动）——**真实复杂更新（代码库/长工作流）的等价类搜索未证**；ATBench 增益大半来自「有参考」而非「等价构造」（随机参考 0.717 vs 检索参考 0.771）；RQ4 更安全选择 66.7% 只是温和优势；B.4 压力测试 n=6 不显著（诚实标注但事实如此）；十代环是程序空间风格化环非完整 agent 自进化系统；「最终零退化」只在监控关闭的本基准上、且是确定性环境；AgentDoG 0.454 是固定 cohort 上的部署形态评估（论文自己声明不归因原文）；v1 无 venue、无公开 repo 链接（工件结构描述完整但未释放）。

## 7 遗留（深读新设）
- **等价类构造的规模化**：大程序空间/真实代码更新上的替身搜索成本与失败率（在线 O(Nm) 的 N 在真实场景会爆炸吗——弃权率会多高？）。
- 弃权率本身未报——「多少更新因找不到可分替身而走弃权」这个部署关键数在正文缺席（只说无替身即弃权）。
- 与 #91 e-process 的正面接口（等价类内 anytime-valid 对照）——两套纪律可否合并成一个验收协议。
- 恶意提案者对抗替身构造（攻击者故意让替身搜索找不到可分替身——论文未讨论对手模型）。
- ATBench 上的等价构造版（若发布方能补原生读出）。
