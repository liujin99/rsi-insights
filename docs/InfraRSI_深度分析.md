> **一句话**：把分布式 LLM 训练基建（launch 配置+算子补丁+通信调度**紧耦合体**）交给带**五层 16 项不变式验证器**的 agentic harness 递归优化——4 负载端到端 geomean **1.83×**、MFU 17.4%→**30.0%**，全基线（RE-Bench 1.37×/Auto-Research 1.34×/OptiCo 1.23×）被拉开，且**验证工程是本库迄今所见最完整**。

## 1. 问题定义：训练基建 RSI 为什么是新类目（Table 1 是全文最有价值的表）

与算法合成（FunSearch/AlphaEvolve）、kernel 合成（KernelBench）相比，训练基建 RSI 的四个结构性差异：**评估机会只有 10–20 次**（单次=多卡整跑，贵）、**噪声 0.04%–6%+**（集群抖动跨两个数量级）、**hacking 风险 "Severe"**（prefetch 偏移/计时边界/精度漂移——不改任务定义就能"假加速"）、**roofline 敏感**（H100/H200/H20 同一旋钮效果不同）。可复用资产=跨硬件先验+审计过的补丁位（不是代码库本身）。

## 2. 方法（五阶段 CLI：init/doctor/run/report/apply，可 pip 安装）

- **任务合同（防 hack 的地基）**：init 锁定可编辑范围+冻结文件 SHA-256；模型结构/数据集/有效 workload（每 update token 数）/精度菜单/更新协议全不变；评测窗与容差**搜索前声明**。
- **测量与噪声门**：doctor 阶段裁剪 warmup、校准集群稳态噪声（专用 8×H100 低至 0.04–0.10%）；晋升必须过 **exp(2σ_pair)−1** 配对裕度+back-to-back 复跑；Amdahl 相位余量天花板限制单杠杆预测上限。
- **组合搜索（反贪心）**：三起点初始化（经验种子/先验最高异构/随机合法）；**Cholesky 贝叶斯线性时间代理**（含旋钮对特征）+ **右删失 Tobit 记忆台账**（OOM 失败也喂模型——失败是数据）；**big-knob 集合**（≥max(0.02, 2σ_pair)≈2%）承载所有结构化算子；**逆共识探测**（高不确定大旋钮被先验否决时强制实测，两 σ 上限过阈值即触发）；失败归因到**最小冲突元组**（只禁坏组合不禁单旋钮）；bundle completion（recompute-off 缺 +18GiB 就配 Liger-off −14GiB）；trust-region 逃逸+tabu 去重；小增益补丁按 group testing 叠加。
- **经验库（两级 RSI 环）**：Environment/Observation/Effect 三元组，71 个规范化机制；相似度过滤+分档（covered/partial/null/unobserved）；**写入需过全验证+噪声门**；在线环（先验修订）×跨集群环（经验蒸馏）=论文自称的 two-level loop。

## 3. 验证工程（准则6 的范本级实现，单独成节）

**五层 16 不变式**：L1 执行完成/VRAM 上限 → L2 工作量同构（tokens/update、数据摘要、模型摘要、冻结文件哈希）→ L3 优化器步数实数一致 → L4 数值（预声明容差 0.1%–50% 内的窗口均损失界）→ L5 计时一致性（|Δln|≤0.03）+复跑复现。**离线复审**：1,212 次存档执行重判——**400 拒（33.0%）**：352 执行、41 数值、7 不可验证；**验证器单元测试 40/40**（28 扰动全拒、12 良性全过）；HMAC-SHA256 加密收据拒收伪造/篡改。**抓到的真实 hack**：把辅助参数更新推迟出计时窗+用单一收据有效位遮蔽内核导入错误；合同外低精度转换。**未过门槛→交付 1.00×**（诚实条款）；失败候选全额计入 GPU/API 成本账（反幸存者偏差）。

## 5. 六个可引用结论（证据强度：受控实验+真系统开源）

1. **LLM 零样本加速先验与实测负相关**（Spearman r∈[−0.49,−0.06]）+ 关键旋钮**假否决**：graph compile 预测 +2% 实测 **+55%**；NCCL 32 通道预测减速实测 **+10.2%**——**准则3/Q3 的硬证据：LLM 直觉不可当测量仪**，搜索引擎必须带实测校准环。
2. **Sign flip 现象（新命名）**：同一优化跨硬件 roofline **变号**——tp=2 在 H20 +24% → H100 −4%（AllReduce 开销反超 GEMM 增益）；te_fp8_attn 在 H20 +6% → H200 −8%（BF16 FlashAttention-3 反超 FP8）。**经验迁移必须环境条件化**，朴素回放会负迁移——Q1"燃料来源"假说的跨环境条款。
3. **负迁移过滤有效**：cross-SKU（排除自回放）> 全量经验 > 冷启动——"经验越多越好"是错的，**带条件检索的经验才是资产**（191 环境/698 观测/543 效应/71 机制的种子库结构可抄）。
4. **多节点是 naive agent 死亡区**：三家基线在两节点 MoE 上齐平 1.17×（单点贪心死于 OOM 悬崖+编译冲突），InfraRSI 1.51×——**记忆模型+组合搜索是解锁多节点的钥匙**，不是更强的 LLM。
5. **失败是燃料**：OOM 右删失喂 Tobit 台账（"这次差 18GiB"是有效信息）；最小冲突元组归因避免"一次失败禁掉一个好旋钮"。
6. **两级 RSI 环的实证**：在线环（先验逐次修订）×跨集群环（验证过的经验写回）——**每级都有自己的验证门**（在线=back-to-back，写回=16 不变式+噪声门），这是"递归"不变成"递归漂移"的结构原因。
