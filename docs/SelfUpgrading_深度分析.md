# Self-Upgrading Embodied Agents（具身 agent 夜间自升级）深度分析

**总表条目**：#156｜arXiv 2611.31117（v1 2026-11-23）｜T2 **[高价值]**（轻评估⑧→**深读坐实**）｜深读批次㉓（2026-11-25，全文 HTML+附录；权重自改线三连之三·收官）

**【一句话】**「终身权重」的具身落地+**权重自改线里测量学最严的一篇**：Qwen3.5-27B 白天在 ALFWorld 家务环境干活（GiGPO 公开提示原样不改），夜里读自己的记录——发现 46% 的回复在 token 限额前根本没产生动作（自我繁殖的浪费链：截断尾巴进历史→下一步更容易再截断），把习惯定位到隐状态里的一个方向、改写 1,184 张量里的**一张**（layer 16 线性注意力输出投影、秩一 W←W+10·uu^⊤W）；**自改前后当自己的考官**（同任务同种子配对测试、2SE 噪声线、256 道它整夜摸不到的保留题上一次性确认）——**夜里确认的 −6.3 点浪费率与白天 held-out 的 −6.4 精确对上**。held-out 48 新种子×数千 episode：完成率 41.6%→45.2%（+3.6，CI[+1.9,+5.2]，p<10⁻⁴，预登记 level 0.01）、五项预登记指标全过。**四夜里只留了这一条编辑、其余三夜全部自己撤回**；四个尺寸里只有 27B 走完全程（2B 干不完任务/4B 测出编辑有害/9B 编辑了但从不要求测试）。

## 2 机制（§3+App C/D——夜的四段）
- **夜给的资源**：① 权重=CPU Python 环境全张量可读、除 embedding/输出矩阵/末层归一化外可写（**禁整张量乘常数**）；② 自己的经历=128 道 opening episode 全记录（每次 prompt/回复/动作/环境答复+汇总计数，**只给计数不给成因**）；③ 跑自己的能力=≤20 轮前向（跑任务=带编辑/不带/都带同种子；**读自己**=重跑某步取隐状态；**候选对比**=一次请求里并排 4 个编辑）。**框架的「方法建议」给诊断优先/多强度测试/2SE 即噪声/只用没用过的题验证——但不点名任何成因、层、方向或强度**。
- **配对测试纪律**：每次对比=编辑版 vs 昨夜自我（同任务同种子），返回逐指标配对差+SE；**2SE 内=按原话报作噪声**。episode 贵→「短 episode（前 10 步）覆盖 64+ 任务」的步数计价法（App B：为 agent 造测量仪器本身是方法贡献——「一个改自己的 agent 首先需要诚实的仪器」）。
- **确认（confirmation）**：300 道保留题（按任务 id 哈希抽、点名请求即拒绝）里用 256 道做**一次性**最终确认；提交条件=**目标故障显著减少且完成率未显著下降**；撤回=权重原样。夜限时 6 小时/160 回合。
- **继承与安全**：夜从「发布权重+全部已提交编辑」出发；opening episode/对比基线/自身推理全部跑在当前权重上——「持住下一夜的 agent 就是上一夜留下的那个」（递归 by construction）。沙箱无网络、梯度禁用；**编辑=命名张量+几行代码，可读可缩可撤**。
- **评测纪律（App D.3，全文最硬）**：**实验计划写在第一夜之前**（任务集/48 种子/sign-flip 置换检验 10 万次/level 0.01/「以任务为单元防 episode 假独立」全部预登记；48 种子是因为 8 种子试点显示差异主要是种子噪声）；全部测试族 union bound ≤0.102；四项附加指标事后追加但**在读到任何结果之前**且各带自己的 level；两处夜间工具变更都注明日期且在适用夜之前。

## 3 主结果核验（Table 2/Table 3 逐行）
- **held-out 五项预登记全过**（48 新种子/任务，同种子逐 episode 配对，任务为单元）：完成率 41.6→45.2（**+3.6**，CI[+1.9,+5.2]，p<10⁻⁴）；40 步内完成 36.5→40.0（+3.5）；**无动作步占比 45.9%→39.5%（−6.4，CI[−7.1,−5.7]）**；tokens/episode 15.1k→13.9k（−1.2k≈−8%）；步数/episode 38.5→37.2。
- **泛化**：没见过的房间 +4.4（37.8→42.2）**大于**见过的 +2.7；60% 任务变多/29% 变少；配对 episode 15.5% 由败转成 vs 11.9% 反向；六任务型浪费率下降全部显著（Bonferroni 后 p<0.008）；三型完成率独立显著（Pick two 60.1→63.9/Examine in light 49.2→58.3/Cool & place 29.2→36.2）。
- **仪器效度（本篇最漂亮的一笔）**：夜里 256 保留题确认测得 **−6.3（SE 1.1）**，白天 held-out 实测 **−6.4**——**自测仪器与外部现实对上**（反馈信号质量谱系的「精确可内化」节点，#101 级读数）。
- **四夜账本**：夜1 撤（20 轮无编辑助益）；夜2 **留**（15 轮 13 次配对测试、5 次明确支持 0 次反对→确认−6.3→SUBMIT；7.7 小时单卡=5.0h 前向+2.3h 确认+69 回合约 2.7 万 token 推理与代码）；夜3 撤（**从已编辑权重出发**、19 轮 14 测试、没能超越自己：「haven't been able to improve upon it」）；夜4 撤（自家小测看着涨、保留题确认无增益、agent 自己给出「overfitting to the specific games」的归因并信任保留题）。
- **尺寸阶梯（Table 3/Fig.38）**：2B 完成率 7.8%——**连夜都开不了**；4B 跑完夜流程、15 次配对测试 **14 次明确反对其编辑**、自己撤（「scaling up MLP weights in layer 31 consistently made things worse」）；9B 161 回合写了 154 个程序、**从未要求一次测试**（把前向请求写进变量然后睡着等结果）、确认 −0.5（SE 0.8）=噪声；**只有 27B 测量着走到一条留住的编辑**——「测量着自己走向一条成立的编辑，是出现在 9B 与 27B 之间的能力」。

## 4 深读金子（摘要外）
- **金子① 病理的自我繁殖结构（Fig.10）**：浪费不是独立事件而是**链式**——连续浪费 0 步后下一步浪费率 27%、连续 6+ 步后 80%；机制=被截断的回复尾巴作为「动作」进入下两步的短历史（环境答「Nothing happens」）。**修的是链的第一环**（回复开头），下游全链统计跟着动（开口「The user...」的回复 55%→46%、开口点题的 35%→41%；「Wait/However/Actually」0/1/2/3+ 次的截断率 3%/50%/86%/95%）。
- **金子② 那一夜的完整实验记录（Fig.36/37 逐回合）**：这是库内最完整的「agent 对自己做实验」的行为学标本——改 layer 63 注意力输出（无效）→反号（无效）→layer 48 MLP（无效）→**读自己的回复发现「失败的开头是 'The user'、成功的开头是 'The task'，verbosity 决定发生得很早」→换早层 layer 16**→+5 反号更糟（「right place wrong sign」自判）→反号 −5（首次出噪）→−15 首次超 2SE（−8.4）→**新任务上回落噪声（−1.1）→加测 128 题（−0.9）**→并排 4 个强度（−5/−10/−15/−20=+1.4/−2.1/−0.8/−2.9）→−20 新任务 −7.2 出噪→−20 全长 episode −9.4 但「repetitive play 上升」→**自选更温和的 −10**（−7.6）→再测一套新题（−2.0 SE 2.6）→申请确认 −6.3→SUBMIT。**换层/反号/加强度/防过拟合/权衡副作用——一个合格研究者的自我实验全流程**。
- **金子③ 「多轮稳定持续」的诚实拆解**：多轮=循环连跑四夜；稳定=**三夜撤回零损伤**（撤回=权重逐位不变）；持续=留下的编辑每夜仍在。但**四夜只留一条编辑、夜 3 明确无法超越夜 2**——「持续改进」实为「单条编辑的收益在 episode 上累积」而非复利叠加。论文用词「multi-round, stable, continual」每个都精确、合起来容易读成「越改越好」——**深读后必须按原文精确转述**。
- **金子④ 9B 的「鲁莽路径」标本**：从不要求测试、编辑自信满满、确认时才被拦下——**「能改」与「会验」在 9B↔27B 之间分家**。四尺寸阶梯=能力四层：干不完任务（2B）/会测但找不到好编辑（4B）/会编辑但不肯测（9B）/测量着走到成立（27B）——**自我测试纪律本身是涌现能力**，连 #102「小模型自伤」的机制解释：不是小模型不会改，是小模型不会验。
- **金子⑤ 一张量解剖（§4.6）**：1,184 张量改 1 张；layer 16 线性注意力输出投影；方向=自己在 layer 63 隐状态上读出的「简洁 vs 截断」对比方向；W←W+10·uu^⊤W=沿 u 分量放大 11 倍；强度由并排测试定（回复长度随强度近线性降、p=0.007）——**「方向哪来、写哪、多强」三问全部可审计**（三行代码在附录）。
- **金子⑥ 撤回夜的证词（Fig.9/D.4）**：夜 4 的最终答复「练习里看到的提升很可能是对所用游戏的过拟合」——**agent 用自己的话说出了训练-测试泄漏的诊断**并服从保留题。多数夜以撤回结束=「另一半结果」（论文原话）。
- **金子⑦ 反测试时扩展方向**：本篇修复=**把计算从步里拿走**（权重里改掉过度思考），而整个 test-time scaling 线在往步里加计算——引 Do-Not-Think 线（overthinking of long reasoning models）为同靶反方向。**与 #154 的病理学读数构成跨论文同构**（见连线节）。

## 5 库内连线（含配对结论）
- **#102（同组前作）**：尺寸阶梯二证「只有 27B 做得到」坐实（#102 推理域同结论）；金子④ 给 #102「小模型自伤」补机制——**自伤=无测试纪律的编辑**（9B 路径）。UIUC 系班底三连发（#102→#107→本篇）全文级确认。
- **#154 Self-WSP（病理同构——本批配对读主结论①）**：#154 的 0.8B=90% 题目思考重复超时、「大半增益=不再卡壳而非会数学」；本篇 27B=46% 回复 token 限额截断、「增益=少绕路而非多家务技能」。**两篇权重自改线的最大单点收益都是移除自毁式退化行为**（重复循环/过度思考）——且都对「编辑增益」构成同一警告：**修病理≠加能力**。两文模型尺寸（0.8B vs 27B）、域（数学 vs 具身）、病理（重复 vs 冗长）全不同而结构相同——库内权重自改线的横断读数。
- **#155 SELFWRITE（同周姊妹篇，配对读主结论②）**：同 27B、同无梯度、同「严格改进才合并」；#155 把**提议宽度**做足（8 独立会话/代、白盒工具箱），本篇把**测量深度**做足（同种子配对+2SE 噪声线+保留确认+预登记 held-out）。**配对结论：权重自改线分出两个互补分工——「广撒网靠 gate 选」与「深测量靠实验走」**；且本篇的统计纪律（预登记/置换检验/union bound）是 #155 缺的，#155 的候选多样性本篇没有。两文都没做 #154 的随机搜索对照（线内共同缺口）。
- **#157 Blind（配对读主结论③——「看得见」的两条路）**：#157 证明 agent **自写的检查**漏掉一半以上自己的失败（一行结果规则反而漏 7-9%）；本篇的夜**不靠自写检查靠外部仪器**——配对测试+保留题确认是框架给的结构，agent 只做读数和决策。**两文合成「自维护的另一面」：检查不能自写（#157 的失败），但仪器可以外置（#156 的成功）**——验收位的归属从「模型」移到「测量结构」。
- **#101 BaseRSI（信号质量谱系）**：金子③ 的 −6.3→−6.4=「反馈信号精确可内化」的教科书读数；2SE 噪声按原话报告=把「噪声就是噪声」写进反馈协议（#106 无信号必漂的反面：这里的信号带刻度）。
- **#91/#104（验收线）**：确认题用 id 哈希保留、请求即拒=质量门的硬实现；「提交条件=故障减少且完成率不降」=双条件门（防「修好 A 弄坏 B」）。
- **#98 组织层/伦理**：「一个改自己的 robot 首先不能弄坏自己」的部署叙事=RSI 安全论述的具身版（编辑可读可撤=审计性主张）。
- **#103（选择>提议）**：夜 2 的过程=提议（层/号/强度）×选择（配对测试+确认）的内化版——agent 自己当选择器，但**仪器不可欺骗**（保留题摸不到、噪声按规则报）。选择纪律在这里产生了唯一一条幸存编辑——结构上支持但同样是「结构符合」级证据（同 #155 的标注）。

## 6 诚实边界
文本环境（ALFWorld）非物理机器人——「embodied」是文本具身、机器人主张是外推；GiGPO 提示原样（好卫生）但仍是单环境单任务族；**四夜一条编辑**——「多轮持续」按原文精确含义转述（见金子③）；无 #154 式随机方向对照（「随机方向+同强度调参是否同样有效」未测——夜 2 的层/号搜索很小，随机基线缺失）；完成率 +3.6 的幅度温和（主要增益在浪费率 −6.4 与 token −8%）；规模阈值只测了同族四尺寸（2B/4B/9B/27B，无中间点）；全部结果单次运行（无多夜重复实验——「四夜」是时序不是重复）；v1 无 venue。

## 7 遗留（深读新设）
- **随机方向对照**（#154 处方）：layer 16 上随机方向+同强度调参 vs 自读方向——方向来自「自我对比」的增量未隔离。
- 编辑持续叠加的多夜版本（夜 3 失败于「无法超越」——更长的夜/更多预算能否产生第二条正增益编辑？）。
- 跨环境复现（TextWorld 族外：真机器人或视觉环境）。
- 9B「不请求测试」的行为学解剖（是工具理解失败还是决策失败——Fig.6 的「写进变量然后睡」值得单独剖）。
- 尺寸阶梯的中间点（13-18B）定位涌现阈值。

## 8 裁定
**T2 [高价值]（深读坐实）**。加分：**库内测量学最严的权重自改篇**（预登记计划+置换检验+union bound+任务级单元+2SE 噪声协议）；仪器效度读数（−6.3→−6.4）；agent 自我实验的完整行为学记录（金子②）；四尺寸阶梯+「会验是涌现能力」（金子④）；撤回夜的诚实披露；与 #102 同组坐实+尺寸阈值二证。不加 T1：文本环境非物理具身；单条编辑+温和完成率增益；随机方向对照缺失（#154 处方线内共同缺口）；单次运行无重复；v1 无 venue。**升级触发器**：随机方向对照；第二条叠加编辑；跨环境复现；venue。
