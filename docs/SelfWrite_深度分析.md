# SELFWRITE（模型自己写自己的权重编辑）深度分析

**总表条目**：#155｜arXiv 2611.29513（v1 2026-11-22）｜T2 **[高价值]**（轻评估⑧→**深读坐实**）｜深读批次㉓（2026-11-25，全文 HTML+附录；权重自改线三连之二）

**【一句话】**回流轴编辑路的**白盒原语+递归继承标本**：Qwen3.8-27B 每代读自己在新题上的推理、在持久 Python 会话里检视自己的权重与激活、用白盒原语（SVD 奇异方向/对错答案激活对比/秩一投影/张量计算）**写程序构造给自己的低秩编辑——全程无梯度无训练**；候选在 500 题隐藏 gate 上与现任逐题配对评分、**只有严格改进才合并、被编辑的模型写下一个编辑**（字面继承）。五代 gate 73.95→76.45，**从未进环的 held-out 76.30→77.75（avg@4）/82.60→84.80（pass@4）**——增益真实但温和（+1.45/+2.20），且**全文没有做 #154 刚立的「同接口同预算随机搜索」对照**。

## 2 机制（§3——四组件）
- **观察**：每代 M_g 答 500 道新抽的 screen 题×4 采样（thinking 模式），编辑器可读**每一份自己的完整答案+推理**；两个免费工具（screen_results/screen_output）按结果过滤/翻页。
- **写**：8 个独立编辑会话（每代），每个 ≤30 轮工具调用、持久 Python 进程（变量/句柄跨调用存活）；白盒工具箱=观察（screen/train/diagnostics 每模块范数-奇异值-有效秩-intruder 分数）/读（svd 任意模块 top-k、**acts 在自己对错答案上的激活统计**）/构造（rank1、from_direction、scale_singular、project_out=−αuu^⊤W）/计算（CPU 沙箱 PyTorch ≤4 张量）/操作（LoRA 算子族 scale/interpolate/combine/ties…）/检查（inspect、**train_loss=只前向 NLL 廉价自检**——「没有工具能评估一个候选」是设计铁律：GPU 工具吃 600s 探索预算+7200s 程序预算）。
- **隐藏配对 gate 选择**：每候选只评一次，500 题固定 gate、与 M_g **逐题配对**（Eq.3），取**严格正增益最大者**合并；反馈给后代=只有统计量（准确率/配对增益/95% 配对 bootstrap CI/修好与修坏题数与 id）——**gate 题面与答案任何工具都拿不到**（「no tool accepts a gate id」）。
- **合并继承**：W′=bf16(W+BA)、FP32 累加；**M_{g+1}（被编辑者）就是下一代编辑器**；上代最佳程序对下代可见、全部尝试可 search_history——「经验累积而编辑模型本身也在变」。
- **约束**：LoRA 秩 ≤64/模块、‖ΔW‖_F/‖W‖_F ≤0.1；允许返回空编辑（=保持 M_g）；连续 3 代无接受即停（实际第 5 代已无接受）。
- **工程**：8 卡=7 个 vLLM 副本热加载候选 LoRA+1 张工具卡（SVD/激活/损失/合并）——**27B 规模上把「评 8 个候选」做可负担**是方法贡献的一部分。

## 3 主结果核验（Table 2 逐行）
- **gate 轨迹**：73.95→75.15（+1.20）→75.65（+0.50）→75.75（+0.10）→76.45（+0.70）→76.45（0.00，第 5 代无接受）。**首代增益最大**；接受编辑 4 条的配对增益全部>0（严格改进纪律兑现）。
- **held-out（编辑器从未见过）**：avg@4 76.30→77.75（**+1.45**）、pass@4 82.60→84.80（**+2.20**）——**编辑越过选择它的题目泛化**（但 gate/test 同出 DAPO-Math 池，同为数学域内泛化）。
- **继承信号（递归正向）**：第 2-4 代的编辑由「已编辑过的模型」写出、仍各找到正增益；第 4 代 +0.70 是第二大步——「被编辑的模型仍是自己权重的有效编辑器」。但 n=4 条接受编辑、无编辑器质量指标，与 #154「留存编辑平均不改变验证精度」的读数对照，**这只是弱正向**（未测「编辑器是否随继承变好」）。
- **成本结构**：一代=8 会话+8 次 gate 评分（每题 4 采样）——**循环随推理而非训练扩展**（论文自评）；27B 上单节点 8 卡可行。

## 4 深读金子（摘要外）
- **金子① 「三切分数据卫生」是全文最硬的部分**：DAPO-Math-17K 去污（对 MATH/GSM8K/AIME/AMC/OlympiadBench 精确匹配或 13-gram 半重叠）→14,738 题→**gate 500（固定、决接受、编辑器永不可读）+test 500（固定、只上报、永不回喂）+screen 500（每代新抽）+train=余 13,238（题面与金答案可读）**——四层角色互斥、按 id 与题面双重不相交。这是把 #104 质量门/#91 留存纪律做到了数据结构级。
- **金子② 「提议者只见统计量」的验收协议**：后代编辑器看到的是上代候选的准确率/配对增益/CI/修好修坏**题号**——永不给题面。与 #156 的「保留 300 题编辑器不可请求」同构：**权重自改线当周收敛出同一个设计模式——提议者看统计、验收靠摸不到的数据**（两文互不知晓，又一处无引用趋同）。
- **金子③ 白盒原语的「自模型」来源**：acts(source='own')=**用当前权重跑「题目+自己的答案」**取激活——编辑方向来自**自己对错答案的激活差**（d=(ā_wrong−ā_right)/‖·‖ 再 project_out）。与 #101 ReGap（教师-学生 gap 无梯度编辑）构成两个独立的无梯度编辑族：#101 用他人 gap、本篇用**自我对比**——「从自己的错误里读出方向」的权重版。
- **金子④ 诚实披露「典型构造来自提示」**：§3.3 明写「a typical construction, **suggested in the editor's prompt**」——对错激活差+投影这个核心招式是**脚手架建议的**，不是模型自发发明。这与 #154 的目录顺序效应同一性质：**接口设计本身在引导编辑内容**——「模型自己写」的说法需要打这个折扣（模型写程序，但程序模板在 prompt 里）。
- **金子⑤ 「无工具可评估候选」的执行细节**：train_loss 是唯一近似评估器（train 题上前向 NLL 差），明确标注为「廉价 sanity check」；真正的选择只发生在隐藏 gate 上——**把「自我评估」与「验收」严格分开**（连 #157「自写检查漏报」的教训在结构上被预先规避：验收根本不用模型自写的检查）。
- **金子⑥ stop 规则与继承档案**：连续 3 代无接受即停（防无限烧卡）；全部程序+结果进 archive，后代可 read_record/search_history——**失败经验也留在环里**（与 #164 ReWeave 的「旧试验重投影」同一记账思想，但这里在权重编辑域）。

## 5 库内连线
- **#154 Self-WSP（对照规范缺口——本篇的最大软肋）**：#154 立的处方「对照同接口同预算随机搜索+随附抽查 run」**本篇全文未做**。8 会话×5 代=40 个候选、留 4 条——**没有随机 LoRA 基线就无法排除「外环选择+通用低秩扰动」贡献了大部分 +1.45**；也没有冻结编辑器对照。诚实地说：held-out 增益证明「被选中的编辑携带真信号」，但**白盒原语相对随机搜索的增量贡献未测**——这正是 #154 证明过不能想当然的那件事（0.8B 上随机打平）。**两文同周同线，一条立规矩一条没守规矩**——引用本篇增益时必须带这个标注。
- **#156 Self-Upgrading（同周姊妹篇，配对读最优）**：同为 27B、同无梯度、同「严格改进才合并」；差异=本篇数学推理域+白盒工具箱+8 候选并行，#156 具身域+方向搜索+13 次配对测试。**配对结论见 #156 文档的配对节**：一个把「提议多样性」做宽（8 会话），一个把「测量深度」做深（同种子配对+保留确认）。
- **#101 BaseRSI（ReGap 无梯度亲缘）**：两个独立无梯度编辑族（他人 gap vs 自我对错对比）；#101 的接受测试纪律（Holm）在本篇=隐藏配对 gate+严格正增益。
- **#103（选择>提议的又一节点）**：8 候选留 1、严格正才合并=选择器在环上；但本篇无归因对照，只能算「结构符合 #103 预言」，不能算又一证据——**证据与结构要分开记**。
- **#91 PACE/#104（验收线）**：gate 反馈带 95% CI+修好修坏清单=把「分数涨就提交」升级成「配对显著才提交」——p-hack 防御的数据结构版。
- **#157 Blind（验收不可自写的权重版预防）**：金子⑤——验收不经过模型自写检查，直接用外部署名数据；与 #157「自写检查一半以上沉默」形成设计层对照（#157 诊断问题、本篇结构上绕开）。

## 6 诚实边界
单一模型（Qwen3.8-27B）单一域（数学）五代；**增益温和**（held-out +1.45 avg@4，且**未报 held-out 差异的显著性检验**——CI 只用于 gate 反馈，test 上没给配对检验）；**无随机搜索对照、无冻结编辑器对照、无白盒原语消融**（#154 处方三项全缺——「白盒原语是否是增益来源」这个核心声称恰未隔离）；典型构造来自 prompt 建议（自发性存疑）；2 人无名无机构无致谢（可信度保留）；gate 固定 500 题跨代复用（对 gate 的选择压累积，held-out 是唯一解毒剂且只差 +1.45）。

## 7 遗留（深读新设）
- **#154 处方落地**：给本篇补同接口同预算随机 LoRA 搜索对照（8 随机会话/代）+抽查 run——**这是本篇结论可信度的头号缺口**。
- held-out 差异的配对显著性（500 题×4 采样的配对检验，论文只报点值）。
- 白盒原语消融：去掉 acts(source='own') 只留 SVD/随机方向，增益掉多少。
- 跨域（代码/推理外任务）与更长代数（stop 规则未触发即止于 5 代）。
- 编辑器继承质量指标（「被编辑的模型是否变成更好的编辑器」——现为轶事级）。

## 8 裁定
**T2 [高价值]（深读坐实）**。加分：数据四层切分卫生+隐藏配对 gate 的验收纪律+无梯度白盒原语工具箱+字面继承闭环（被编辑者写下代编辑）+held-out 正增益；「提议者只见统计量」协议是线的收敛设计模式之一。不加 T1：增益温和且未给 held-out 显著性；**#154 对照规范三项全缺**（随机搜索/冻结编辑器/白盒消融）——核心声称（白盒原语驱动增益）未隔离；2 人匿名署名可信度保留；单模型单域五代。**升级触发器**：随机搜索对照补做并存活；held-out 显著性报告；跨域复现；机构身份/venue 落定。
