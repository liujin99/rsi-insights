# RSI-Prime（训练模型去训练模型）深度分析

**总表条目**：#100｜arXiv 2611.23138（v1 2026-11-17）｜T2 **[高价值]**（轻评估→**深读坐实**）｜深读批次⑮（2026-11-24，全文 HTML + 附录）

**【一句话】****「训练者被训练」的第一份受控教材研究**：把 350 条完整模型训练实验轨迹变成训练数据，按**决策质量**选监督位（AND 保守规则整条屏蔽低质量决策消息）训 GLM-5.3——PostTrainBench 36.56→**48.24（相对 +31.95%）**；深读最值钱的不是这个总分，而是**四路监督对照证明「选择的准则>选择的数量」**与 A.2 的**配比执行偏差样本**。

## 1 出处与身份
- **5 人学术团队（轻评估「机构待核」坐实）**：Dewu Zheng（中山大学）/Yang Ye（Mind Lab，umich 邮箱）/Hongyu Zhang（重庆大学）/Jun Yu（哈工大深圳）/Yanlin Wang（中山大学，通讯）——无工业署名；规模=一个学术小组。
- **谱系**：Related work 自认最近前作=**RSI-Dojo**（Gao et al.，arXiv 2611.03698——后训练环境+轨迹收集+微调 post-training agent）；本文增量=系统化轨迹构造管线（预执行验证/独立监督/中断恢复）+细粒度监督。库内无 RSI-Dojo 记录（新设 watch 候选）。
- **释放**：论文 license CC BY 4.0（文档级）；**数据集/repo 未见释放声明**——复算依赖论文描述。
- 基准锚：PostTrainBench v1.2（Rank et al.，官方权重），与 #105 AdaObs 共用=交叉锚。

## 2 机制（§3 四段管线）
- **任务收集与验证**：七类任务（数学推理/代码/工具交互/知识/信息处理/语言/指令跟随）从 HF/论文/官方 repo 自动收集→统一任务接口→**预执行三重验证**（协议/评分器/运行时，正负控制对照+覆盖检查，不过则修到过）。
- **轨迹构造**：agent 在环境里自主跑训练实验（目标模型 Qwen3-4B-Base，1×H100 累计 10 小时），**独立 supervisor 监控+中断恢复（保会话/工件/累计预算，干预与 agent 行为分开记录）**；过滤=PostTrainBench 四个轨迹 judge + 相对改进门槛 **g>0.5**（提交模型的改进须超 Instruct–Base 参照差距的一半）。
- **决策识别**：annotation agent 窗口化读轨迹（窗口边界挂起待新证据再归组，防窗口切割强拆决策）；三轮独立校验多数通过才保留。决策=Analysis/Choice/Execution 三段，可跨消息（54.95% 决策引用多条消息、57.01% 消息涉及多决策）。
- **质量标注+动作分类**：GLM-5.3 对每决策三维各出 3 份评估、维度内多数投票；动作分类=人工卡片排序 taxonomy（5 主类 20 子类+Other）+模型辅助 3 份多数投票。
- **决策级屏蔽训练**：**AND 保守规则**——消息的 z_a=∏q(d)（所挂决策全过才监督，任一失败整条屏蔽；无决策关联的消息也屏蔽）；与原监督 mask 相乘做选择性 SFT（保留全上下文，只动监督范围）。保留 **76.25% 消息（68,027/89,211）/75.48% token（33.48M/44.35M）**；屏蔽中含 12,094 条无关联消息（956,754 token——不因无关联就算有问题）。
- 训练配置：GLM-5.3，2 epochs，bs 32，lr 1e-4，cosine，warmup 0.05；agent harness=DeepSeek Harness（400K 上下文/128K 输出/最大推理档）。

## 3 主结果核验（Table 3/4 逐行）
- **四数字全坐实**：GLM-5.3 基线 **36.56**（附录 B：三独立运行均值）→ Full SFT **45.61（+24.75%）**→ Decision SFT **48.24（+31.95%）**；六任务分项 14.44→25.33/38.46→49.50/28.94→33.93/83.65→89.69/23.58→50.21/79.27→83.54（AIME +12.23、HealthBench +26.63 最大）。
- **相对排位**：48.24 超 Gemini 4 Argon（47.92）/Opus 5.5（47.84）/GPT-6.1 Sol（46.45）/Fable 5（46.31），距 SOTA Fable 5.1+Claude Code（53.68）−5.44。
- **监督策略四路对照（Table 4，本批最值钱的表）**：Full SFT **45.61**（100%/100% 保留）｜tool-failure masking **45.12**（87.69%/89.15%——按执行状态屏蔽工具失败消息）｜step-level masking **43.21**（77.38%/76.63%——ATLAS 重要步选择法适配）｜Decision SFT **48.24**（76.25%/75.48%）。**step-level 与 Decision 保留率几乎相同（76.63% vs 75.48%）而总分差 5.03**；step-level 低于 Full SFT 2.40。

## 4 深读金子（摘要外）
- **金子①「选择的准则>选择的数量」**：Table 4 三路对照给出三层结论——(a) 减监督本身不带增益（step-level 减 23% token 反而 −2.40）；(b) **执行状态信号不够**（tool-failure 45.12<Full——「工具跑通了」不证明选的数据/训练法/评测是对的）；(c) **决策质量准则才带增益**（+2.63 over Full）。这对姊妹库是直接的：**监督位选择>全轨迹均匀监督，且准则要选「判断质量」而不是「执行状态」**（连 #99 金子② loss 脱钩——loss/exit code 都是执行侧信号）。
- **金子② A.2 配比执行偏差样本（四例）**：TOD-ProcBench **选了 55:45 混合比、构造出来的不一致**；ManyIH 只覆盖所选指令组之一；XStory 过滤规则把大部分目标训练源排掉；FoFo 脚本漏掉计划的修正-再生成步——**决策（计划）与执行（落地）的分离**：轨迹级过滤（g>0.5）保证结局好，不保证中间每步做对了；对用户配比研究=「配比决策的执行层漂移」的现成失败标本。
- **金子③ 人工审计（A.4）**：400 条随机抽样、双标注+第三仲裁；接受率 98.75/99.50/97.50%，raw agreement 99.50/99.75/99.25%，**κ=0.831/0.799/0.866**——LLM 自标注的可靠性有审计纪律（准则 6 弱形态）；但论文自认**只测精度不测召回**（「audit samples existing decision records, it does not estimate the recall」）。
- **金子④ 基线三运行的方差（附录 B）**：GLM-5.3 在 Arena Hard Writing 三次运行为 **25.79/37.03/52.57**（±13 点级）——同 agent 同 harness 的运行间方差就这么大；这既是对 +31.95% 声明的诚实注脚（基线均值抹掉了方差），也是 #103 Resolution Hypothesis「方法排名<运行间方差」读数在本库同周的第二个来源（且出自自家对照实验）。
- **金子⑤ 活动分布（A.1）**：90,738 决策中**评测与诊断 38.43%+数据准备 27.09%=65.5%，model training 本身只有 9.09%**——「训练模型」这项工作的真实构成大半是造数据和看结果（姊妹库配比线的经验印证：数据侧>训练侧）。
- **金子⑥ 问题率按动作类型（§3.7）**：总体 problematic 仅 7.58%，但 **implementation optimization 16.89%、data source selection 12.80% 最差**——数据源选择（配比核心决策）是问题率最高的子类之一：终点好+轨迹过滤过，中间的配比决策仍是最容易做错的环节。
- **金子⑦ 行为质量与任务分数同升（§5.3）**：Decision SFT 的质量通过率 96.11%（Full 87.25/step 90.16/tool-failure 91.65），learning objective 79.27→95.05/data source selection 84.38→95.73/inference config 81.77→95.61——**分数增益伴随行为质量增益**（不是 hack 分数的增益），且排除评测类后仍 95.63 vs 87.40。

## 5 库内连线
- **#105 AdaObs**：PostTrainBench 同基准（本文主评测、#105 迁移评测）——两文构成「训练者训练」与「观测面进化」在同一个尺子上的对照。
- **#72 Self-HPO / #62 SimpleTES**：轨迹经验→监督的路线族；本文把「经验」压到**决策粒度**并按质量选——轨迹记账（#62）的监督位版。
- **#98 error reproduction**：7.58% problematic 决策=决策粒度的错误结构（过滤后仍存）。
- **#103 Resolution**：金子④基线方差呼应其方法级方差读数；Lim et al.（2026）发现「agent 能修实现但极少根据反馈改初始策略」被本文引为直接动机——决策质量监督正是对准这个病灶。
- **#91 PACE / #53 撤走纪律**：监督选择=acceptor 侧问题（选什么进训练=选什么算数）。
- **回流轴（#93/#65/#101）**：本文不是 harness 内化——是「实验经验→训练者能力」的**元层内化**（L1 监督位在 agent 侧，harness 不动）。
- **姊妹库 data-mixture-insights**：金子①（监督位选择+AND 规则）+金子②（配比执行偏差）已追注接口文档。
- **RSI-Dojo（2611.03698）**：最近前作，库外——新设 watch 候选（遗留）。

## 6 诚实边界
学术小组（非工业）；350 轨迹规模小；**+31.95% 是相对值**（绝对 36.56→48.24，且基线三运行方差 ±13 点级、只对基线做了 3-run 平均）；**质量标注由 GLM-5.3 自评**（自我标注循环——人工审计 400 条缓解，但 precision-only）；**数据集/repo 未声明释放**；HumanEval 训练-评测内容重叠（论文已披露）；单 harness（DSH）/单 agent 底座（GLM-5.3）/单目标模型（Qwen3-4B-Base）；v1 无 venue。

## 7 遗留（深读新设）
- RSI-Dojo（2611.03698）是否入库（最近前作、被本文正面比较）。
- 数据集 RSI-Prime 释放与否（释放则监督选择准则可第三方复算）。
- GLM 之外底座复算（决策标注+屏蔽策略是否模型无关）。
- step-level masking 低于 Full SFT 的机制解释（ATLAS 准则为何在此域负贡献——重要步≠好决策）。

## 8 裁定
**T2 [高价值] 维持（深读坐实）**。加分：四路监督对照干净（同数据同模型同预算）+人工审计 κ+行为质量与分数同升+A.2 诚实失败标本。不加 T1：学术小组、数据未释放、单底座单 harness、无 venue、相对值+基线方差未做显著性披露（附录 B 只给均值）。**升级触发器**：数据集释放+第三方复算；GLM 之外底座；venue；RSI-Prime 被第三方用作训练教材。
