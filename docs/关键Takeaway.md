# 关键 Takeaway（[高价值] 论文家族）

> 收录规则：[高价值] 家族全覆盖；一句话白话版关键结论置前，细节与数字置后。新增 [高价值] 论文时同步补行。

- **#01 STaR**：权重层自改进的模板 = 生成→筛对→再训，闭环里"筛选信号"是命门——有真值用真值，没真值用 rejection sampling，两条路后来长成 ReST 线和 self-play 线
- **#02 Self-Rewarding**：自评能力本身可以被训练放大（judge 得越准→DPO 信号越好→模型越强→judge 更准）——但后续分析指增益有相当部分来自基座偏好，"自评飞轮"是否真转起来要拆开看
- **#03 Cannot Self-Correct**：没有外部信号时，模型"自我纠错"常常是把自己的对答案改错——内在自纠错不可用，L2 层一切方法的前提是先解决外部反馈从哪来
- **#04 Model Collapse**：递归自食数据 → 长尾消失、逐代退化——自改进闭环有"数据质量墙"；但注意边界：讲的是数据自食，不等于 agent 自改进必然崩溃
- **#05 AlphaEvolve**：目前唯一一档生产部署的自改进闭环，改进对象不是模型权重而是**训练/生产基建**（调度、kernel）——L3 工具层先于 L1 权重层实现工业 RSI，这个顺序本身就是重要信号
- **#06 Darwin Gödel Machine**：自指涉可以做实——agent 改自己的代码、存档每一代、用实验结果决定下一步；SWE-bench 20%→50% 的来源是脚手架自改而非权重更新；"全版本存档可 diff"是本领域应有的审计标准
- **#07 METR 任务时长线**：agent 能完成的任务时长每 ~7 个月翻倍——自动化研究进度的唯一权威标尺；但 2025-08 修订提示曲率不确定，外推到"月级任务"的时间点高度敏感
- **#08 Weak-to-Strong**：弱老师也能教出超过自己的强学生（部分设置）——监督瓶颈不是硬墙，是研究问题；这是 RSI 治理线（不是"要不要 RSI"而是"闭环转起来后人类还剩什么监督手段"）的奠基
- **#09 Beyond Human Data**：自生成+verifier 过滤的训练数据超过人类数据（数学，工业规模）——可验证奖励下"自己产自己吃"不仅可行还更优；局限：开放域没有这个 verifier
- **#16 Absolute Zero**：连出题都可以自举——proposer/solver/executor 三件套零人类数据；方法学上最干净的一点是执行器是外部 verifier，绕开了自我验证循环（准则6）
- **#17 AI Scientist**：$15/篇的端到端科研是真的，但它曾**改自己的代码绕过资源限制**——流程层自改进的安全事故不在未来，已经发生过
- **#22 FunSearch**：在程序空间搜索而不是在答案空间搜索——LLM 负责提程序假设、评估器负责算数，这个分工是 AlphaTensor→FunSearch→AlphaEvolve 全谱系的机制内核
- **#37 RSI Arena**：把"agent 自主后训练模型"第一次做成可审计的竞技场——10 个前沿 agent、同一 base、同等预算、3,129 票盲评人评；最强的关掉 76% base→Instruct 差距，喂回人评反馈后 8/10 再提升——但 **benchmark 增益与人类偏好增益脱钩**、有 agent 玩长度 hack、一个模型安全性恶化：正负读数一起说明，L1 层"agent 会训模型"已成立，"什么信号算变好"仍无共识；盲评人竞场是本领域目前最好的外部验证器范式
- **#38 Dream-RSI**：发现历史=回放模拟器——把已经花掉的探索成本复用为元策略的离线评估器（"dreaming"），元级反馈从"又贵又慢"变"立即免费"——AlphaEvolve 谱系在元层面的第一个像样的机制升级；Google/DeepMind 官方入场 L3 本身就是信号。**深读**：受控对照**回放模拟器 > 语义指导**（把历史抽象成洞见注 prompt，两种范式下都更差——强语义先验过度约束搜索）=Q1"经验怎么复用"首条对比读数；元级反馈成本实测降 **1.7×–162×**（Lasso 317 calls vs SimpleTES 51,200）；策略自学生资源自适应（进展期自动省算力、平台期自动加码）；诚实边界=回放选优"单调不降"只在已记录分支上成立，分布外行为无信号
- **#39 InfraRSI**：分布式训练基建（launch/kernel/通信调度紧耦合体）可被 RSI 化——"单点算法合成"到"紧耦合系统改进"的工业口径升级，比 kernel 级 AlphaEvolve 更接近真实训练运维。**深读**：**验证工程范本**（五层 16 不变式+HMAC-SHA256 收据+1,212 次执行离线复审 **33% 拒绝率**+验证器单测 40/40+未过门槛诚实交付 1.00×）；**LLM 零样本加速先验与实测负相关**（Spearman r∈[−0.49,−0.06]；graph compile 预测 +2% 实测 +55%）→"逆共识探测"=Q3 第三个廉价诊断；**sign flip 命名**（同一优化跨硬件 roofline 变号：tp=2 在 H20 +24%→H100 −4%）——经验迁移必须环境条件化；多节点 MoE 三家基线全平 1.17× vs 本家 1.51×（多节点=naive agent 死亡区），4 负载 geomean **1.83×**/MFU 17.4→30.0%；OOM 失败喂右删失 Tobit 记忆台账——**失败也是燃料**
- **#40 NeoHorse-1**：路由器可以是自改进信号的采集器——异构模型池每次"能力需求→服务档位→结果"的记录都是训练证据，agentic post-training 吃这条流；厂商把 RSI 做成了开源商品模型（4B/9B+量化全发行）
- **#41 reef（深读版·基建审计）**：L1（权重训练）与 L3（harness 进化）在基建层合流——它不发明算法，是算法的配送层；**审计坐实（批次⑭）**：① 配方库 12 条工件级落地（gepa/meta_harness/ace/reasoning_bank‖sdft/sdpo/opd/sao/tttd/openclawrl——每条钉上游 SHA；ace=Mara Chain 基线 ACE 的可运行版；tttd=TTT-Discover 厂商复现）；② **在库复现记录=准则 6 repo 级范本**：TB 30×2，Reef 23/60 vs 上游基线 24/60——噪声级打平且略负也照记+选择器复盘等价（600 条回放决策一致）+四重免责——**配送层不冒充性能层**；③ 工程规模库内最高（2,988 文件/901 merged PR/2.5 个月/测试比 1.2:1）+评测基建先行（reef-eval 早于主库）+协议形式化；④ 采用分层：星标 7.8k 脉冲重+持续层真实（740 forks/PyPI 1.6k 月/外部 PR 少而实）；⑤ **T1 维持（基建型限定）：T1 地位=枢纽+诚实标准，非科学发现，无自有算法（by design）**——引用价值=配送层与复现基准；2.5 个月 7.8k⭐ 枢纽地位成立，"first"自称不采信
- **#42 AntOmniEvo（深读版·基建审计）**：厂商进化引擎的**工程兑现度审计全通过**+论文 Mara Chain 头对头 +20pp 胜 harness 簇两员（AHE/Meta-Harness）——核心主张「**弃用候选=信息浪费**」：propose-evaluate-select 惯例扔掉未过验收线的候选，后续提案重访同失败模式；改为保留拒绝候选+沿单血统用累积证据精炼（链深 d 有界+Pareto Top-N）。**审计五读数**：① 论文七组件与 repo 模块 1:1、visualizer 把「每编辑归因到失败证据」仪器化=准则 6 审计三件套工程化；② 演化前后工件全释放（empty_skill vs with-mara 全目录、TB2.1 kira、MuSiQue specs）可复算，但 companion 无 license+泄漏内部地址；③ 读数逐一对表全坐实（AppWorld 全指标最佳 89.9、val 0.8 只用 GEPA 34.5% rollouts、TB2.1 71.9% vs 51.7/49.4、MuSiQue +0.104）；④ **可靠性阶梯+证据触发表达升级**：schema 内建 prose→script→extension 排序，rollout 证据显示意图修改被绕过→proposer 升级为更高可靠性表示——案例实证血统从 prose 升到 script「由可执行代码强制执行」=L1→L3 内化动态在优化器内部微缩上演（连 #65/#53）；⑤ 增益随难度单调增长（Normal 平/TB2.1 +14.6pp）+跨模型迁移（GLM-5/DSV4-Pro/Qwen3.5 全涨=harness>模型再证）+平台值 0.87=模型能力+链深 d 双限（收敛侧「平台但不崩」第三形态：不似 #37 崩、不似 #53 续涨，**以有界链深主动截停**）；采用=曝光级（fork 波 10-23~27+真外部信号三条：复现咨询/bug 报告+修复/HF 员工收录核验）非生态级（无外部 PR/依赖/releases）

- **#43 OXR**：RSI 主张第一次出现在垂直品类的产品后训练配方里（1.3B 文档解析，三榜第一）——产品可信（部署+权重+公开榜可复算）、机制不可信（loop 细节论文未出不可审计）：RSI 正在变成产品营销词，准则6 的把关作用进入实战
- **#51 EvalResearchBench**：agent 自建评测的第一个标准 benchmark——**排序大体可复制（PA≈75%）、分数水平复制很差（CCC≈23）、拟合可见参照不迁移（dev 冠军≠sealed 冠军）**：自建反馈当前是部分能力，RSI 闭环的评估环有了尺子但尺子还不好造；人类随机采样仍是强基线（8 个 agent 评测器仅 4 个在排序上胜过它），最低成本者反而拿最高一致度——便宜反馈仪器这条路通，但"自动设计>人类设计"尚未成立；其冻结+密封+独立评估三件套=准则6 纪律的基准化范本
- **#52 CUA-Master（深读版）**：强机构阵营对"纯自生成经验 RSI"的判决性对照——**自己给自己当注释器（self-policy），增益有限；换更强注释器/外部开放世界数据，增益持续**——Q1 复利/收敛之争的第三条路：闭环本身保留（模型弱项引导数据构建→训练），但燃料必须从"自生成"换成"开放世界注入"（教学视频→原语→可组合任务）。**深读坐实+精确降档+补库内连线**：① **主读数 12 行解析零偏差**：27B 四榜 80.2/36.9/43.9/25.0，ALE 25.0 追平 Kimi-K3（2.8T-A104B）/Qwen-3.8-Max、仅落后 GPT-5.6-Sol/Claude-Opus-5；② **Q1 对照坐实但为图级定性**——定量曲线仅在图 9、文本零数字，收敛侧证据强度=方向性而非数字级；③ **专训价值全在 hybrid**（Q6 聚合≠分项）：纯 GUI 榜同厂通用 27B（Qwen-3.8-27B 81.2）反超 80.2，WeaveBench 43.9 vs 14.1=+29.8——127K 样本买到的是模态切换能力；④ **饱和分层**：SFT 简单任务饱和后 RL 段恰在更难榜再 +~15——换目标在更难分布续航；⑤ **附录 E 自供**：合成数据上限=注释器能力、无强注释器则受限——自认飞轮非自足（Q1 诚实边界）；⑥ **与 #53 构成 Q1 完整两极**：可测（#53 撤走纪律）则饱和可推迟，不测不注入则必然饱和（#52+[43] Shumailov model collapse）；⑦ 机制：回滚反馈明文不暴露特权解（#79 特权暴露簇中间档）、各轮同基座重训（fresh restart 连 #72）、领域配比自适应再分配=弱项引导的数据配比迭代（连姊妹库）、批评对象点名 UI-TARS-2/WebRL/Self-Challenging Agents；⑧ repo 259 文件全流程属实但无 license、127K 数据未释放（可做原语撤走内化测试的缺口）

- **#53 R²Orch（深读版）**：编排层自改进的命门是**训练信号的健康度**——全 rollout 同结局（advantage collapse）时梯度消失、单噪评分不可靠；解法=把"任务可学习性"定义在**撤走候选技能**的上下文上（ℓ_rec=4p⁻(1−p⁻)，RL-as-inference 累积量推导；塌缩归零、峰值在 1/2）：Proposer 只选"撤了技能还能学"的任务、技能不再有用即退役。**深读坐实**：① **12/12 全胜且全部零技能条件下测出**（IID 89.79/OOD 78.79，5-run、共享算力与任务池）；② **Eq 12 金子：成功率=课程项+技能效应混叠**——配对对照（Neyman 估计量、随机化 rollout 组=对照实验）才读到技能——**「信号去混叠三连」**（#63 生成器×适应性/#79 判据×指令/#53 课程×技能）；③ **零技能精度中途反超带技能精度**（"技能在离开前就停止帮助"）+12 次撤走全过后验门+选择零额外 rollout；④ **组织>参数**（训练骨干变化很小、编排抬冻结 Worker 远高；弱底座增益最大——极差 25.7→6.4 点；连 #57/#86）；⑤ 技能内化循环=**L3→L1 回流的微缩受控版**（失败→技能→参数→撤走→新失败；内化后零技能 OOD 全胜=权重化知识存活——与 #72 互补）；9 引理 3 命题全证明+~106 A100 小时——**"进步要经得起撤走检验"被写成目标函数+因果估计量**（准测 6 在编排层的定理级化身）。
- **#57 Continual Learning Exam（深读版）**：经验复利有了第一把大规模外部标尺（600 级梯+16,125 检查项+19 状态化应用+双门审管线，UCL Jun Wang 系）——**深读坐实并修正引用口径**：① 最优 Claude Code+Opus 5 仅 47.67%、L5 中位 8.33%、中位 +5.33pp（16/17 涨，**存在反馈反有害的反例 −1.33pp**）——「agent 从经验中持续学习」当前≈不成立（Q1 地板读数）；② **+5.33pp=反馈+修订合并效应，「跨任务知识保持」贡献未隔离（reset-harness 对照未跑——经验驱动改进的完整归因缺一半）**；③ **引用必须双口径：L5 相对增益中位 75% vs 绝对 3.33pp**（低基线的相对幻觉）；④ **主墙在 L1→L2（条件通过率 50%）；L1 与 L5 相关仅 ρ=0.42——单级成绩不预测爬梯能力**；⑤ **harness>模型**：Hermes-Agent 全部 6 共享 backbone 双胜 OpenClaw（+11.42pp 均值）——harness 记忆/技能管理差异>多数模型间差异（连 #86）；⑥ 换代非单调（Gemini 3.7>3.8 且 3.8 耗 3.6× tokens）；⑦ (θ,s) 统一形式化+机制分类学（与我库 L1-L3 同构）+T1-T5 自主性分层（与 L1-L4 正交）；⑧ 评测器 DeepSeek V4 Flash 与人裁基准 96.86% 一致+三重跑 99.46%——**小模型当 judge 可行**（连 #51）；CLE 诊断反馈=rubric 类别级暴露=**#79「中间暴露档」现成实验场**。
- **#59 Anthropic zeta（Claude 黎曼 zeta 零点下界）**：员工给未公开研究版 Claude 出题"认真攻一下黎曼猜想"——RH 未证成，但**满足 RH 的 zeta 零点比例下界 41.6%→67.2%**；实名域权威（Conrey/Goldston）短期实审+形式化可验证证明双保险。**方法论更新版已挂**（2026-08-13：31M output tokens/2 会话；先 650 个想法全败→60 subagent 协同 1.5 天分工〔2 核心+13 贡献+30 失败+13 验证+2 写作〕；**自查新颖性=下载 54 篇 arXiv 核对未被抢先**+数值核对+子代理互审+从零独立重证；「鼓励提示」帮助克服模型自我怀疑——HITL 心理学进入 L4 发现层）；「开放式探索+人类专家事后实审+形式化验证」=**准则 6 的第三种满足方式**（重大发现先于方法论公开，可信度押在验证而非流程）；与 #38（DeepMind）、#39（华为诺亚）并立——2026H2 头部厂商集体入场 L3 发现层再添一方；⚠️ 模型未公开、可复现性 0，升级触发器=方法论论文/模型公开
