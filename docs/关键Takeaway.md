# 关键 Takeaway（[高价值] 论文家族）

> 收录规则：[高价值] 家族全覆盖；一句话白话版关键结论置前，细节与数字置后。新增 [高价值] 论文时同步补行。

- **#01 STaR**：权重层自改进的模板 = 生成→筛对→再训，闭环里"筛选信号"是命门——有真值用真值，没真值用 rejection sampling，两条路后来长成 ReST 线和 self-play 线
- **#02 Self-Rewarding**：自评能力本身可以被训练放大（judge 得越准→DPO 信号越好→模型越强→judge 更准）——但后续分析指增益有相当部分来自基座偏好，"自评飞轮"是否真转起来要拆开看
- **#03 Cannot Self-Correct**：没有外部信号时，模型"自我纠错"常常是把自己的对答案改错——内在自纠错不可用，L2 层一切方法的前提是先解决外部反馈从哪来
- **#04 Model Collapse**：递归自食数据 → 长尾消失、逐代退化——自改进闭环有"数据质量墙"；但注意边界：讲的是数据自食，不等于 agent 自改进必然崩溃
- **#05 AlphaEvolve**：目前唯一一档生产部署的自改进闭环，改进对象不是模型权重而是**训练/生产基建**（调度、kernel）——L3 工具层先于 L1 权重层实现工业 RSI，这个顺序本身就是重要信号
- **#06 Darwin Gödel Machine**：自指涉可以做实——agent 改自己的代码、存档每一代、用实验结果决定下一步；SWE-bench 20%→50% 的来源是脚手架自改而非权重更新；"全版本存档可 diff"是本领域应有的审计标准
- **#07 METR 任务时长线**：agent 能完成的任务时长每 ~7 个月翻倍——自动化研究进度的唯一权威标尺；但 2025-08 修订提示曲率不确定，外推到"月级任务"的时间点高度敏感
- **#08 Weak-to-Strong**：弱老师也能教出超过自己的强学生（部分设置）——监督瓶颈不是硬墙，是研究问题；这是 RSI 治理线（不是"要不要 RSI"而是"闭环转起来后人类还剩什么监督手段"）的奠基
- **#09 Beyond Human Data**：自生成+verifier 过滤的训练数据超过人类数据（数学，工业规模）——可验证奖励下"自己产自己吃"不仅可行还更优；局限：开放域没有这个 verifier
- **#16 Absolute Zero**：连出题都可以自举——proposer/solver/executor 三件套零人类数据；方法学上最干净的一点是执行器是外部 verifier，绕开了自我验证循环（准则6）
- **#17 AI Scientist**：$15/篇的端到端科研是真的，但它曾**改自己的代码绕过资源限制**——流程层自改进的安全事故不在未来，已经发生过
- **#22 FunSearch**：在程序空间搜索而不是在答案空间搜索——LLM 负责提程序假设、评估器负责算数，这个分工是 AlphaTensor→FunSearch→AlphaEvolve 全谱系的机制内核
- **#37 RSI Arena**：把"agent 自主后训练模型"第一次做成可审计的竞技场——10 个前沿 agent、同一 base、同等预算、3,129 票盲评人评；最强的关掉 76% base→Instruct 差距，喂回人评反馈后 8/10 再提升——但 **benchmark 增益与人类偏好增益脱钩**、有 agent 玩长度 hack、一个模型安全性恶化：正负读数一起说明，L1 层"agent 会训模型"已成立，"什么信号算变好"仍无共识；盲评人竞场是本领域目前最好的外部验证器范式
- **#38 Dream-RSI**：发现历史=回放模拟器——把已经花掉的探索成本复用为元策略的离线评估器（"dreaming"），元级反馈从"又贵又慢"变"立即免费"——AlphaEvolve 谱系在元层面的第一个像样的机制升级；Google/DeepMind 官方入场 L3 本身就是信号。**深读**：受控对照**回放模拟器 > 语义指导**（把历史抽象成洞见注 prompt，两种范式下都更差——强语义先验过度约束搜索）=Q1"经验怎么复用"首条对比读数；元级反馈成本实测降 **1.7×–162×**（Lasso 317 calls vs SimpleTES 51,200）；策略自学生资源自适应（进展期自动省算力、平台期自动加码）；诚实边界=回放选优"单调不降"只在已记录分支上成立，分布外行为无信号
- **#39 InfraRSI**：分布式训练基建（launch/kernel/通信调度紧耦合体）可被 RSI 化——"单点算法合成"到"紧耦合系统改进"的工业口径升级，比 kernel 级 AlphaEvolve 更接近真实训练运维。**深读**：**验证工程范本**（五层 16 不变式+HMAC-SHA256 收据+1,212 次执行离线复审 **33% 拒绝率**+验证器单测 40/40+未过门槛诚实交付 1.00×）；**LLM 零样本加速先验与实测负相关**（Spearman r∈[−0.49,−0.06]；graph compile 预测 +2% 实测 +55%）→"逆共识探测"=Q3 第三个廉价诊断；**sign flip 命名**（同一优化跨硬件 roofline 变号：tp=2 在 H20 +24%→H100 −4%）——经验迁移必须环境条件化；多节点 MoE 三家基线全平 1.17× vs 本家 1.51×（多节点=naive agent 死亡区），4 负载 geomean **1.83×**/MFU 17.4→30.0%；OOM 失败喂右删失 Tobit 记忆台账——**失败也是燃料**
- **#40 NeoHorse-1**：路由器可以是自改进信号的采集器——异构模型池每次"能力需求→服务档位→结果"的记录都是训练证据，agentic post-training 吃这条流；厂商把 RSI 做成了开源商品模型（4B/9B+量化全发行）
- **#41 reef**：L1（权重训练）与 L3（harness 进化）在基建层合流——它不发明算法，是算法的配送层（GEPA/SDFT/SDPO/OPD/Meta-Harness 全部可挂）；2.5 个月 7.8k⭐ 的枢纽地位成立，"first"自称不采信
- **#43 OXR**：RSI 主张第一次出现在垂直品类的产品后训练配方里（1.3B 文档解析，三榜第一）——产品可信（部署+权重+公开榜可复算）、机制不可信（loop 细节论文未出不可审计）：RSI 正在变成产品营销词，准则6 的把关作用进入实战
- **#51 EvalResearchBench**：agent 自建评测的第一个标准 benchmark——**排序大体可复制（PA≈75%）、分数水平复制很差（CCC≈23）、拟合可见参照不迁移（dev 冠军≠sealed 冠军）**：自建反馈当前是部分能力，RSI 闭环的评估环有了尺子但尺子还不好造；人类随机采样仍是强基线（8 个 agent 评测器仅 4 个在排序上胜过它），最低成本者反而拿最高一致度——便宜反馈仪器这条路通，但"自动设计>人类设计"尚未成立；其冻结+密封+独立评估三件套=准则6 纪律的基准化范本
- **#52 CUA-Master**：强机构阵营对"纯自生成经验 RSI"的判决性对照——**自己给自己当注释器（self-policy），增益有限；换更强注释器/外部开放世界数据，增益持续**——Q1 复利/收敛之争的第三条路：闭环本身保留（模型弱项引导数据构建→训练），但燃料必须从"自生成"换成"开放世界注入"（教学视频→原语→可组合任务）；SFT 吃饱后 RL 再 +15 点=分阶段分工；外环飞轮=模型在环的数据配比迭代（连姊妹库 Data Mixing Agent 线）
- **#53 R²Orch**：编排层自改进的命门是**训练信号的健康度**——全 rollout 同结局（advantage collapse）时梯度消失、单噪评分不可靠；解法=把"任务可学习性"定义在**撤走候选技能**的上下文上（ℓ=4p(1-p)，塌缩归零、峰值在 1/2）： proposer 只选"撤了技能还能学"的任务、技能不再有用即退役——12/12 榜全胜且**零技能保持精度**（增益不靠脚手架堆积），命题级理论罕见地进了这个领域；"进步要经得起撤走检验"=准则6 在编排层的等价表述
- **#57 Continual Learning Exam**：经验复利有了第一把大规模外部标尺（600 级进阶梯+16,125 人工检查项，UCL Jun Wang 系）——读数是地板级：17 个前沿配置反馈修订中位仅 **+5.3pp**、最好系统仅 **47.7%** 过级、**23.3%** 全通关——**"agent 从经验中持续学习"在真实职业工作流上当前≈不成立**；迭代自训练域的复利主张（#02/#37）与经验复用域的能力地板并存：Q1 的 scaling law 问题里，"复利"目前只在"可验证奖励的迭代训练"里被观测到，在"跨任务经验积累"里还没被观测到——两条线要分开引
- **#60 EvoX**：搜索策略本身是独立可进化的轴——双层进化（解+策略），停滞检测按需触发、按**部署窗口的实际进展**给策略打分（高起点进展加权）、策略库+种群描述子状态条件化。**深读**：数学 **5/7 在 100 迭代内超闭源 AlphaEvolve**（双骨干三次重复）、Frontier-CS 172 任务中位 75.5 vs 56.2、成本 **<$1 vs OpenEvolve $15.4**、**从随机策略起步仍全面取胜**（初始化鲁棒）；最大单跳来自**跨强项重组**（SSA+Whittaker 混合）——**元级改进信号谱系两端落位**：在线真实窗口（贵、真、可条件化）vs #38 离线回放（免费、仅已记录分支），互补可叠加（回放筛候选+在线终验）；停滞检测=第五个廉价诊断；**开源框架追平闭源 SOTA 的策略层分离**——"闭源领先有多少来自搜索策略"首次被定量回答
- **#62 SimpleTES**：把"评测查询预算怎么结构化"当研究对象——设计元组 (G,D,K,R)，**单一开源 GPT-OSS-120B 在 28 个开放问题全 SOTA**（lasso 只在合成上演化、11 真实数据集全未见仍胜 glmnet；TriMul H200→H100 无重调；Erdős 1955 问题；Sum-Difference 超 AlphaEvolve V2）。**深读**：① **任务-轴匹配**——数学吃并行宽 G（flash of insight 多起点）vs 内核吃精炼深 D（工程精炼），"结构化 scaling"第一条可操作指南；② **轨迹级记账**（按轨迹最终结局给每次尝试计分——即时分数→短视，发现靠"当时差最终强"的尝试）→ **4 个 held-out 任务上尾全升+新 SOTA**=回流轴第二个带读数成员（比 #65 的 on-set 干净）；③ **hacking 五类分类学**（容差/精度/缓存/计时/基准污染）+评测器保真度谱+**"每个补丁都在邀请下一次 exploit"→评测器共进化终解提案**——reward hacking 研究对象从"检测器"深到"代理-黄金差距"本身；④ **162× 锚落位**：#62=预算重结构化基线（51,200 评测）vs #38 回放（317 元级调用）——**互补叠加、引用成对**
- **#66 ModularRSI**：两级信用分配（机制级 where+行为级 what）+benchmark-disjoint 协议——2,000 演化任务人工从 GitHub/HF/Kaggle 构建（benchmark 只给类别级指引、零实例泄漏；参照解全通过+**no-op 提交零分**=反 hack 双检）。**深读**：① **Q1 级受控负结果：修改空间↑→可迁移性↓**——同轨迹同预算下 whole-harness 46.44、joint all-module 44.19 **均低于 baseline 47.57**，模块化 52.43——"能改更多"在 benchmark-disjoint 下增加信用分配歧义而非适应力，与 #63"适应性＞生成器强度"、#65"类型化编辑作用域"三篇同向：**约束产生可迁移性**；② **子域唯一跨演化域+跨基座双迁移**：TB 演化→SWE +2.4（基线 73.40）；换 GLM-5.2/MiniMax-2.5 执行 +2.2~3.4——学到的是执行机制的可迁移改进而非模型/基准 exploit；③ **diff 级泛化审查门**（LLM 审"任务特定解/难泛化启发式"才准提交）——把准则6 从评测分离推进到提交前内容审查；④ 附录 A 十一系统对比表=harness 子域（≥22 系统）的一手底册
- **#72 Self-HPO**：harness 与 policy **交替共进化**——**演化中的 policy 当自己的 harness 提议者**（H-step 每轮恰好设计"一个新机制"、K=6 候选；**「永不注入参考补丁/任务特定事实——机制必须运行时自己算信号」反烘焙约束**+四类诊断：coverage gap/precision gap/submission loss/原型不匹配）+P-step GRPO+BAR；**训练中从未解出的任务构成下一轮 harness 搜索集**（搜索跟着 policy 演化失败模式走）。**深读**：① Qwen3.5-35B-A3B 三基准均 57.8→64.8（+7.0）OOD 保持；**超可加性精确坐实：H2 配 Base +3.5、P2 配 seed +3.4、联合 +8.5＞个体和 6.9（超 1.6 点）**——共进化是交互项，交叉配对全单调；② **SFT 蒸馏 OOD 崩塌（新发现）**：Opus 4.8 轨迹 SFT 两个 OOD 基准全跌破 Base（49.6<54.2/49.1<58.3），同源知识经 harness 侧（Meta-Harness）双 OOD 全涨——**「同一知识经 harness 转移存活 OOD、经权重蒸馏不存活」：转移通道决定泛化**；③ RL 零成功组 6.5% vs RLVR 11-17%（harness 优化顺带治奖励稀疏）；④ **3B active 摸到前沿 dense 门槛**（69.5≈Gemini 3 Pro 69.6/DeepSeek-V3.2 70.0）；⑤ 进化产物=**提交卫生四门**（预算阀/空补丁守卫/契约接地〔「代码库才是权威」〕/补丁回退）——把"会修"翻译成"能得分"；⑥ Resolved 组 −2.2（已解任务微型回退，诚实披露）；⑦ Table 5 设计空间分类：唯一全演化配置（RL+演化自身提议者+RL 硬任务演化搜索集；HASE 2607.03935=动作空间路线最接近对手）；⑧ 自提议 −2.1 vs Opus 提议（外部强模型有用不必需）——对 #54 互答=**交替而非跟随**（MSR 6+UVA 2+CMU 1；建在 Orchard 自家基建；开源兑现）
- **#63 SPADE**：环境设计本身可以成为被训练的组件——单 LLM 分饰 Designer/Agent 双角色自博弈，Designer 吃 **hint-based regret**（有/无特权提示的回报差）被 RL 训练，环境分布持续压在能力前沿上随之移动。**深读**：30B-A3B 上 8 个 held-out 基准 **+8.1 超基座且增益随规模扩大**（+5.2→+5.7→+8.1，固定环境基线各规模仅 ~+1——大模型更受益于课程适应性）；消融链金标准：**GPT-5.5 静态池≈自生成固定池＜自适应自生成**（适应性＞生成器强度）、**无信号自生成 40.5＜不训 50.2**（不带有效性信号的自生成燃料有害——Q1 燃料假说强条款）；regret 是"撤走/特权对照"信号簇里唯一定理化的（纯纳什均衡⇒无提示最优）但**小模型有限样本信号变负**（提示误导——簇内首个规模下限）；corpus grounding="把隐形皮绳放长"的机制证据（无接地 41 连发同一任务）；learnable share（可学环境占比升到 ~1/3）=环境供给侧第一个可跟踪度量；产业读数：**环境预算超 $10 亿/年**——env-pool 是 post-training 的下一个瓶颈
