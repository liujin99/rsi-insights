# Feedback-Free Self-Evolution（无反馈技能自进化的负结果+机制+反设计）深度分析

**总表条目**：#106｜arXiv 2611.25534（v1 2026-11-19）｜T2 **[高价值]**（轻评估⑦→**深读坐实**）｜深读批次⑲（2026-11-24，全文 HTML + 附录；与 #101 配对读——「信号源生死件」双证之负路）

**【一句话】**Q1 收敛侧的最强新证+机制命名：让 6 个模型逐轮改写专家技能（无任务/无运行/无判断）×30 轮——**每个模型在每个基准都更差**（SkillsBench 平均 −14.6 点、30 轮后「技能≈没有技能」）；改写把技能**拉向模型自身先验、最先丢先验外的知识**（0/10 item 存活 23.1% vs 10/10 item 84.2%）；把先验外知识放回去能恢复大部分掉分（恢复 8.8 vs 4.4 点，两倍差）——**专家技能的价值恰在模型自己写不出的部分**。反设计 SkillDiff（就地标记先验外 item）+4.8 点零改动修复。

## 2 机制（§2-§3 三步因果链）
- **设置**：模型只看技能文本+一句话主题重写×30 轮递归；同一模型当 agent 用重写后技能（GPT 用 Codex/Claude 用 Claude Code/其余用 OpenHands）；3 基准=SkillsBench（87 任务 8 域、容器跑+确定性 verifier）+SRA-Bench 两子集（LogicBench 760 题 19 技能；MedCalc-Bench 1100 题 55 技能，单调用+gold 技能进 prompt）；技能文档重写、脚本/参考文件不动。
- **先验采样（方法学工具，可搬）**：让模型**只从一句话主题写 10 个「自写技能」**（不看专家文档）=模型对该主题先验的操作化采样。
- **① 重写拉技能向先验**：TF-IDF 余弦距离（以自写技能平均成对距离归一化）1.37→1.19（第 5 轮）→1.22（30 轮）——前几轮移动大后趋平，**技能停在原版与自写版之间**；但第 5 轮后距离不变而 pass rate 继续掉——全文距离不显示后几轮还在删什么。
- **② 选择性丢失（item 级）**：技能机械拆成 items（标题/列表项/代码块/表格/段落；SkillsBench 6605+SRA 2376 个）；按「10 个自写技能中有几个包含该 item」度量先验接近度。**30 轮后 0/10 item 平均只存活 23.1%、10/10 item 存活 84.2%（gap 61.1pp）**；逐模型全部显著（Δ +36 到 +74）；第一轮就出现、跨 item 类型一致；换 judge（GPT-6.1-Sol 复判）gap 49.5/52.5 仍稳。
- **③ 因果恢复实验**：30 轮重写版为基础（先删冲突弱化版形成 common base）→恢复三类版本：**只恢复先验外 item 找回 8.8 点（两倍于恢复其他 item 的 4.4 点）；全恢复 10.2≈只恢复先验外**——是「什么回来了」不是「多少文本回来了」。

## 3 主结果核验（§2.2/§4.2 逐行）
- **下降轨迹**：**第一次重写就掉 7.1 点**（平均）；5 轮 10.9；30 轮 14.6；逐 agent 30 轮后掉 10.3-23.0 点。前几轮掉最快、后趋缓。
- **30 轮后技能≈没用**：LogicBench 86.2%→71.4%（**=无技能水平**）；MedCalc-Bench 89.7%→78.7%（**低于无技能的 81.1%**）。多步使用（SkillsBench）与单调用（SRA）两种用法都掉。
- **SkillDiff（§4）**：同先验采样+item 判定→0/10 item 就地打 **[FOCUS]** 标+标题下加注（要求 agent 把标记 item 照原样带进 plan、别简化成通用做法）；**移除标与注=byte for byte 原版**。SkillsBench **+4.8 点平均、六模型全正**（GPT-5.6-Luna +12.6/GPT-6.1-Sol +5.7/MiMo-V2.5-Pro +3.4/Qwen3.7-Plus +2.3/Claude Haiku 5.5 +3.4/Qwen3.8-Flash +1.1）；**同批对照**（同批跑原版防批次漂移——连 #103 分辨率纪律）。
- **附录对照（B 系列）**：B.2 无 web search 的重写损失更大（搜来的外部内容也拉不回先验外知识）；B.5 重复重写链：每条链几乎同样路径、每条链都先丢先验外 item；B.6 **从原技能删先验外 item 比删其他掉更多**（删除成本反向验证）；B.7 A 模型的重写技能给 B 用也掉（跨模型负迁移）；A.3 judge 三重可靠性（标签一致/差距不依赖 judge/无损失处找不到损失）；A.4 40 个自写技能：每十个样本找到几乎相同 item、**先验外 item 几乎从不被写**。

## 4 深读金子（摘要外）
- **金子① 「专家技能的价值=模型先验外的知识」（反 Dunning-Kruger 定理）**：技能的有用部分恰是模型自己写不出来的部分——无反馈重写只能拉向先验，**在数学上不可能增加先验外知识**（技能是唯一来源，改写最多保住）。直连 #52 CUA-Master 附录 E「合成上限=注释器能力」：自产数据/技能/记忆的价值上限=模型自身之外的知识存量。
- **金子② 先验采样的操作化（工具可搬）**：「10 个自写技能+item 级 judge」把抽象的「模型先验」变成可测采样——可用于任何「这份外部材料有多少信息是模型自己就有的」审计（对姊妹库：**数据配比里每个域的「模型先验外含量」可用同法估**）。
- **金子③ iterated learning 理论接口**：文化演化文献的「posterior 采样下迭代学习收敛到学习器先验」——给 Q1（RSI 收敛问题）接上了领域外的理论根基：**无反馈递归改写不是 bug，是迭代的数学宿命**。
- **金子④ SkillDiff=零改动面修复家族**：不重写、只标记+引导注意——连 #66（约束产生可迁移性）：修复方案的选择面越窄越耐用；[FOCUS] 移除后 byte-for-byte 还原=**可回滚修复**。
- **金子⑤ 谱系定位（与反馈依赖方法的边界）**：SkillFoundry/SkillOpt/MetaSkill-Evolve/MASA 靠 verifier；SelfEvoSkill 靠配对执行；SSSO 靠 LLM judge；SkillAxe 靠规则——**它们都在「执行信号」上做文章**；本文证明信号拿掉后剩下的是什么（先验引力）；SkillLearnBench 四轮先升后降的 side result（B 系附录互证 #98）。
- **金子⑥ 第一轮就掉 7.1 点**：最常用的「让模型顺手改写一下技能/提示」操作，单次就有实害——实践级读数，不需要 30 轮才成立。

## 5 库内连线
- **#03（T1 推理层负例）**：三层负例齐——#03 推理层/#98 记忆层/本文技能层——**Q1 收敛侧证据链成型**（三个独立层、三种工件、同一失效模式：无外部信号→回归先验）。
- **#98 error reproduction**：记忆层负例同族（抽象持久化允许错误复利）；SkillLearnBench 四轮先升后降=两文互证。
- **#103 Resolution Hypothesis（同批对照③）**：互补失效模式——#103=有信号但信号噪声大（选择=掷硬币）；本文=干脆无信号（重写=必然漂移）；**反馈信号质量谱系**：无信号必败→噪声信号随机→精确信号可内化（#101）。
- **#101 BaseRSI（同批配对）**：#101 内化成功用的信号=教师-学生 gap（**外部锚=harness 的逐 block 效应**）；本文证明无外部信号的重写必然降质——**信号源是生死件**的同年同月双证。
- **#52/#66**：金子①（反 Dunning-Kruger）+金子④（零改动面）。
- **姊妹库 data-mixture-insights**：金子②（先验外含量审计）——对配比线的「合成数据价值=模型先验外含量」读数；模型生成的合成语料在同意义下**不增加模型先验外信息**（连 UltraData/自产数据线的边界判读）。
- **Q1/Q6**：无反馈自进化=必然贬值（Q1 收敛侧）+反馈信号是分水岭（Q6）。

## 6 诚实边界
范围=技能文档重写（脚本/参考文件不动）；「granularity of skill updates」自认局限（item 级拆分粒度）；judge 为 LLM（但换 judge+假阳性/假阴性三重检查稳）；30 轮单链（B.5 重复链稳）；6 模型覆盖 2026 前沿档；无 venue、v1；「恢复」实验以 common base 为前提（删了弱化冲突版）。

## 7 遗留（深读新设）
- SkillDiff 在跨域技能/更长技能上的泛化（论文只测 SkillsBench 的标记增益）。
- 先验外含量审计与 #103 Quality@K 的组合：proposer 产出池里「先验外 item 数」当质量代理的可行性。
- 与姊妹库合成数据线的交叉判读（合成语料「先验外含量」测量方案）。
