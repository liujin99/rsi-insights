# AdaObs/Sage-Evolve-Preview（观测自适应：平台期=观测耗尽而非能力耗尽）深度分析

**总表条目**：#105｜arXiv 2611.26132（v1 2026-11-19）｜T2 **[高价值]**（轻评估⑦→**深读坐实**）｜深读批次⑳（2026-11-25，全文 HTML+附录；与 #104 配对收官队列②——「反馈信号家族」第五成员）

**【一句话】**observation-side 机制命名+正面解法：**把固定的 anchor 目标与 loop 实际用的 active observation 解耦**——大多数 post-training RSI 环把 anchor 总分当唯一观测，增益早早停滞；**平台期可能反映「观测耗尽」而非「能力耗尽」**。AdaObs 在平台期让控制器沿固定梯子爬：**L1 细化诊断粒度**（把总分拆成 item 级失败组/协议切分/行为指标）、**L2 升难度**（加更难子集、held-out 参考模型引导的「有信息量通过率带」）、**L3 加相关任务**（同能力方向不同任务形）；验证过的增量融回训练、**每个 checkpoint 仍对 anchor 评分守恒目标**。8 个独立优化 anchor 全胜 FixedObs：**均值 66.4→73.7（matched 数据预算）**、超两个现成 Qwen checkpoint；进化后 harness 原封迁移 PostTrainBench 双后端都升（30.3→37.2/35.7→42.3）。

## 2 机制（§3——两个时间尺度的进化）
- **七阶段环**：Observe（最新 checkpoint 在 active observation 上收反馈）→Analyze（识别能力缺口）→Plan（最小可证伪的数据干预）→Produce（合成/下载增量）→Validate（质量/来源/污染三道门）→Train（基数据+全部保留增量的全参数 SFT）→Evaluate（anchor+active 双评分）；**实验记忆 M 存已确认结论与失败结果**（不重复提已失败干预）。
- **平台检测**：边际收益 MR_t=评分变化/新增数据量，指数平滑后**尾窗 w 内全部低于 ε 才判平台**——按数据量归一（不是按轮数）；**换观测=新 phase、清空历史、不同观测的分数永不直接比较**（口径纪律）。
- **保留规则**：增量改善 anchor 或 active 任一评分（在小 anchor 回归容差内）即保留累积——**active 测当前假设、anchor 守不变的目标**。
- **三级梯子（顺序固定、内容自选）**：L1 只改诊断粒度 g_r（总分→item 级失败组/协议切分/行为指标如超长率/think 触发率——**最便宜：不采新数据就能暴露缺陷**）；L2 加难子集 δ*（**难度累积不替换**；held-out 参考模型引导选「够难给 headroom、不难到没反馈」的档）；L3 加相关基准 B*（同方向不同任务形；观察集累积扩大）。每步只改观测三元组 O=(B,δ,g) 的一个分量。
- **harness 慢钟更新**：从 M 挖 recurring agent 失败（误诊/污染/冗余探索/跳过验证/过早终止）→有界候选改可编辑面（阶段 prompt/技能/工具接口/记忆规则/观测控制器规则）→**在修复集（含目标失败）+回归缓冲（既往成功决策）上重放**→修复目标+保住回归+过接口/来源/prompt 预算检查才提交；**评估器/anchor 观测/验证门不可变——harness 不能靠改自己的考试提分**。

## 3 主结果核验（Table 1/2/3 + §5 逐行）
- **主表（Qwen3.5-35B-A3B-base 全参 SFT；8 anchor 各跑独立环；FixedObs 与 AdaObs 同起始数据同配方+可比有效增量预算）**：AdaObs **8/8 全胜**，均值 **66.44→73.66**（阅读理解 61.7→68.9、指令跟随 71.2→78.4）；**超两个现成 checkpoint**（Qwen3.5-35B-A3B 62.76/Qwen3.6-35B-A3B 65.17）；最大单项 LongGenBench +12.93、SummHay +11.38（**最高 headroom 基准上增益最大**）。单杆消融（附 Table 4）：**每杆单独只恢复部分增益，全梯子才够**。
- **PostTrainBench 迁移（Table 2）**：进化后 harness **原封不动**迁移（不跑初始 harness——即已收敛的 prompt+控制器启发式）：GLM-5.2 后端 30.3→**37.2**、Claude-Opus-4.8 后端 35.7→**42.3**（4 个后训学生模型 Qwen3-1.7B/4B/SmolLM3-3B/Gemma3-4B 各 avg@4）——**机器而非后端在起作用**。
- **L1 案例（监督格式缺陷）**：MRCR v2/AA-LCR 早期停滞、大量超长截断答案；L1 拆出超长率 0.31+think 触发率 0.91（高但不满——不是不会想而是想开了收不住）→归因：**无 think trace 的增量混进 think-based 450k 基座稀释监督格式**→全部增量重 rollout 成带 think 格式：超长率 **0.31→0.08**、触发率→0.99、MRCR 87.20→90.33、AA-LCR 66→69——**总分上不可见的缺陷，L1 细化后变成可行动的**（改格式不改内容/量）。
- **B.8 案例（长上下文悬崖——最清晰的单一图示）**：FixedObs 在 LongBench v2 上只剩两个旋钮（重平衡已下载公开数据/调配方）；七轮日志每旋钮只动零点几、平台判定于 55.0。**L1 按输入长度拆分暴露异质性：语料 85% 条目 <32k、仅 3% >128k，而 LongBench v2 有 1/4 评测质量 >128k**——短桶近天花板 68.0 水平、长桶在地板 36.8 纹丝不动（**训练旋钮供不出数据里没有的长上下文行为**）；总分 55.0=两桶混合、混合正是「局部失败读成无增益可用」的机制。L1 暴露缺口后加 >128k 长上下文数据：长桶 36.8→39.4、总分破平台 55.0→55.7（与 L1-only 消融吻合），再接 L2/L3 到终点 58.12。**增益完全来自改了「看什么」**。
- **迁移不对称（§5.3 机制）**：同基准内每 10k 增量对目标子集的迁移——**难→易强**（8-needle→2-needle +2.1、128k→32k +1.7）、**易→难弱或负**（低至 −0.4）；**对自身已饱和的观测仍是其他目标的好源**（8-needle/64k 对角 ~0.1 但行内离对角高至 +2.1/+1.2）——**「没有单一固定观测全程有用」的机制级证明**（为什么 adaptive 优于 fixed 的答案）。
- **harness 进化降失败（§5.4）**：六类缺陷里前五类（误诊/污染/冗余探索/跳过验证/过早终止）**进化后显著下降、双后端一致**（可编码直接补救的缺陷）；runaway generation（解码器性质）只微降——归因于持久 harness 更新而非更强后端。
- **方差纪律（附 B.6）**：主表 mean±std（0.48-0.82，**「方法间排序不是采样噪声伪影」**）；PostTrainBench 的 std 只算 4 学生独立 avg@4 通道的采样噪声、**明确拒绝把学生规模差折叠进误差条**（系统性容量差≠测量噪声——两种效应分开）。

## 4 深读金子（摘要外）
- **金子① 「考卷不变、显微镜变」的解耦设计**：anchor=目标（不可变）、active observation=镜头（可进化）——**防 reward hacking 的结构位**（评估器/anchor/验证门不可变）与「让反馈重新有信息」的需要同时满足。比「动基准抗饱和」（AutoBencher/ArenaBencher 路线）和「动训练分布/奖励」（self-play/curriculum 路线）都不同：**只动「选择增量的观测」，两半文献在一个环里统一**。
- **金子② 平台检测的按数据归一边际收益**（MR=Δscore/Δdata 指数平滑+尾窗判）——比「轮数进不去分」更口径正确的平台定义；**换观测清史**（分数不可跨观测比较）=把「口径漂移」当设计纪律而非事故。
- **金子③ B.8 长上下文悬崖=分布错配的最小教学案例**：语料质量再高、配方再调，**桶内天花板/地板的混合平均会把「数据里根本没有的行为」伪装成「无增益可挖」**——对配比迭代：均值型 proxy 分数同构地隐藏桶级缺口（连姊妹库「单一信号先脱钩后耗尽」判读的实证版）。
- **金子④ 迁移不对称的操作含义**：**从难处产出的增量反哺易处**（+2.1/+1.7）、反向弱/负——**课程设计的方向性判据**：先难后易有非对称红利；饱和源仍是他处好源——「这条信号没用了」≠「这个方向没用了」。
- **金子⑤ L1 是零成本杠杆（最便宜的最先试）**：L1 不采新数据、只重切已有评测输出——把「总分不动」变成「哪个桶不动」；**顺序固定的梯子=从免费到贵的成本排序**（L1 重新切→L2 采更难→L3 加任务面）。
- **金子⑥ L2 的「有信息量通过率带」选档法**：held-out 参考模型引导选「难到有 headroom、不难到没反馈」的难度档——**难度选择的可操作判据**（连 #62 结构化预算同层：预算给结构、这里给档位）。
- **金子⑦ harness 修复的回归缓冲验收**：每个候选在「修复集（含目标失败）+回归缓冲（既往成功）」双集重放——**改 harness 与改权重同款纪律**（连 #101 BaseRSI 每处编辑可单独移除：可回滚+防回归是进化系统的通用验收形态）。

## 5 库内连线
- **Q1（平台期解释）**：第三种解释成型——分布自锁（#52）/技能饱和之外新增**观测面耗尽**；且给出正面解法（三杆梯子），把「停滞」从判死改成诊断分岔。
- **反馈信号家族第五成员（本批轴级）**：#106 无信号必漂→#103 噪声信号掷硬币→#101 精确信号可内化→**#105 信号可续命（观测自适应=让信号重新有信息）**——从「信号质量谱系」延伸出「信号是可再生的资源管理问题」。
- **#103**：anchor 总分=低分辨率观测，L1=提分辨率；B.6 方差纪律+「排序非噪声伪影」声明=103 式纪律的正面样板（报 std+明确两种效应不混）。
- **#153 DataMaster**：同 PostTrainBench 生态；DataMaster 树搜策展=进化「作用对象」、**本篇点名的正是 DataMaster 类系统固定的那件东西（观测）**——互补位的准确陈述。
- **Piccolo 金子②**：单一信号先脱钩后耗尽——本篇把「耗尽」机制化（观测面耗尽）并给出响应（换/加观测）。
- **#62 SLDBench**：同层不同解（#62 结构化评测预算定结构；本篇让结构进化+平台触发）。
- **#150 Curation-Bench**：策展环=固定观测下的数据面进化——AdaObs 补上其未动的观测面；两者可叠。
- **#101（同批配对）**：金子⑦（回归缓冲验收=可回滚+防回归同构）；#101 内化信号位置、本篇进化信号面——harness 进化的两个正交面。
- **姊妹库 data-mixture-insights**：**直接可搬的三杆梯子 playbook**——配比迭代的 proxy 分数平台期：L1 把 STEM accuracy 拆成子域/难度/行为指标（零成本）、L2 加难子集（有信息量通过率带选档）、L3 加相关任务；金子③（桶级混合隐藏缺口=均值型 proxy 的同构陷阱）+金子④（难→易不对称=配比内课程红利）——已递接口文档追注④。

## 6 诚实边界
**Preview 版**（自认）；两个能力域（长上下文阅读理解+指令跟随）、单一基模型 Qwen3.5-35B-A3B；全参数 SFT 无 RL；8 anchor 各自独立优化（**不是单模型跑全部基准**——主表口径是 per-benchmark loop 各自最佳 checkpoint 聚合，与参照 checkpoint 的对比须注意此口径差）；无代码/材料释放声明；增益是 8 anchor 均值（对单 anchor 的提升 0.6-12.9 不等）；PostTrainBench 迁移的 std 只覆盖采样噪声（学生容量差另报）。

## 7 遗留（深读新设）
- 阶段间分数不可比（清史纪律）与「anchor 一直量」的双轨记账——保留增量判据（两分数任一改善）的误差累积分析未做。
- L2 难度档引入的「难子集增量→易子集」红利在配比场景的定量验证（姊妹库实验设计候选）。
- harness 修复候选的重放=对实验记忆的离线评估——记忆偏差（只存主导失败标签）对修复选择的影响未测。
- Preview→正式版的域扩展（RL/代码/数学）与材料释放。
