> **一句话**：冻结 **Claude Opus 5** 上的"能力驱动"harness 进化——任务按**共享能力需求**重组为能力树，Creator 在节点上生成**排除目标任务布局与解法的**简化可验证世界（Real2Sim2Real），Explorer 沿树**选择性继承**进化模块成 harness 树，Router 用能力先验选配置——4 轮迭代 **Train 39.1→73.2 / Unseen（16 非机器人）42.1→64.1（超 Codex 47.5/DeepSeek 46.2 参照）/ 两台真机 0→60%**；**防泄漏纪律是论文级范本**。

## 1. 定位与立场

- **攻击面**：现有 harness RSI 集中在文本域（编码/数学）+ 任务特定进化——任务相似时可行，异构任务上会过拟合；全局单 harness 又装不下冲突需求（如具身任务的性能-效率权衡）。
- **核心洞察**：表面形式不同的任务可共享底层能力需求（论文自举例：ARC-AGI-3 与 Micromouse 都依赖感知+状态跟踪）——把"共享机制"变成共同学习目标，泛化就有抓手。
- **立场声明（Position）**：从 task-driven 转向 **capability-driven** self-improvement——这同时自然导出"多专业化 harness+按能力路由"的系统形态。

## 2. 方法（三角色三树，全部冻结底座）

1. **Harness 形式化**：6 协议纯函数模块（Perception/Memory/Inference/Planning/Orchestration/Loop），模块=公开记录的纯函数、无隐藏状态访问，只有 Memory 可声明显式 carry；进化只改模块配置，θ 冻结。
2. **Stage1 任务树**：公开基准规范化为规格（目标/观测/动作/反馈/完成判据/预算），归 5 需求域（规则发现/约束求解/感知控制/多智能体/长时程）；**train/unseen 分割在能力归纳前固定**。
3. **Stage2 能力树**：独立 agent 提能力类别→judge 合并→reviewer 独立核查；确定性能力序 ≺ 在建树前固定，路径排序后 **Trie 合并共享前缀**。**Real2Sim2Real**：Evolver 从节点需求（+后代+代表任务公开规格）设计简化训练关卡，**显式排除目标任务布局、私有证明与解题轨迹**；Creator 用节点 harness 实现关卡，host 验证器池查绑定/执行/状态转移/渲染/完成；**冻结筛选 harness 只接纳"中间性能带"内的世界**（预定义难度维度上调整）——世界太难太易都不收。
4. **Stage3 harness 树**：选择性继承=P⊕L 右偏并集（局部覆盖父模块）；**父更新须严格更高 host 验证性能才被孩子继承**（父级单调不劣）；Creator 只在验证器检测到失败时进化，迭代末按学习序合并去重（近重复保留先学者）成新 Base。
5. **Router**：公开任务信息+检索经验（cos≥0.5、≤10 条、2 万条 FIFO）+已执行配置的性能-成本摘要；**提交前必须给证据化理由**；unseen 能力标签在**预测账本 hash 锁定前不可见**。

## 3. 防泄漏与审计设计（本库视角下最亮眼的部分）

分割先固定 / 能力序确定性 / hash 链执行记录 / **hash 锁定预测账本** / 冻结筛选 harness / 中间性能带准入 / 技术失败记零分 / 无效选择无回退 / skills 与树和路由隔离（只做评测时准备、5 次试跑轨迹总结后冻结）。这套纪律与 **#51 ERB（冻结+密封+独立评估）、#39 InfraRSI（五层 16 不变式）** 并列，构成 2026Q4 本库准则6 的**三大方法学范本**。一处措辞待核：局部模块准入"requires no score increase"（§3.5）——疑为"不要求分数提升即准入（以验证为准）"或笔误。

## 5. 六个可引用结论（证据强度：受控消融完备，但全自报）

1. **能力驱动 > 任务驱动**（组织轴受控）：同样 token 预算下，能力树+选择性继承胜过 15 个任务专属 harness 与全局单 harness——**组织方式本身是增益来源**。
2. **模拟课程 > 真实任务直练**（同拓扑 +3.51/+4.95）：Real2Sim 生成的"排除答案的世界"是比原任务更好的训练场——学习环境与评估环境分离的工程化实证。
3. **L3 层迭代增益可持续的新数据点（Q1 正面）**：迭代 2-4 仍 +9.4/+6.4——与 #37 Stage 2、#52 SFT+RL 分阶段并列；但都是 ≤4 轮、harness/数据层而非权重层，仍非 scaling law；Eleusis 下降提示**逐基准不稳定**。
4. **路由逼近 Oracle（差 2.65）**：多专业化 harness+语义路由=可部署的"多 harness 联邦"，且省 token——"一个模型一套 harness"不是唯一形态。
5. **真机迁移成立但样本极小**：n=2 任务、20% 粒度成功率——"能力跨到物理域"是初步证据不是结论。
6. **防泄漏纪律=论文级范本**（见 §3）——对后续所有 harness RSI 工作的复制价值高于其具体数字。
