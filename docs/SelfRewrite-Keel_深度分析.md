# 权重自改线（LM-Rewrite + Keel）深度分析

**总表条目**：#102 **Language Models Can Rewrite Their Own Weights**（arXiv 2611.21885，v2 2026-11-18）+ #107 **Keel**（arXiv 2611.25257，v1 2026-11-18）｜#102 T2 **[高价值]**、#107 T2（轻评估→**深读坐实**）｜深读批次⑮（2026-11-24，全文 HTML + 附录，同线双作合并读）

**【一句话】****「模型当自己的优化器」首证（27B 自改）与 agentic 权重编辑 VLM 首例（frontier 改小模型）是同组同日的平行双作**：深读坐实全部 headline 数字（+6.6/修复 56%〔文本〕83%〔图像〕of base/2B 不编辑 4B、9B 自伤 27B 成功），并挖出三颗库级金子——**「规模带来的是编辑周围的实验而不是编辑本身」**（9B 打印了离群统计却没注意到）、**「反馈信号选择=找移动噪声最多的可观测」**（repair objective 的设计理由）、**「修复≠复原」**（写进去的是自己的值）。

## 2 机制（两文各自的设计核心）
### 2.1 LM-Rewrite：session 设计（§2）
- 模型=Qwen3.5 家族四档（2B/4B/9B/27B，Gated DeltaNet 线性注意力+全注意力混合，thinking 开）；任务=DeepScaleR 数学（3,000 练习+1,000 held-out，对 MATH-500/AIME/HMMT/AMC/OlympiadBench/GPQA-Diamond 去污染）。
- **预算与约束**：B=20 次前向+ C=200 次代码运行（CPU Python 会话、梯度与优化器禁、不许加载模型/开进程/联网）；**输入嵌入/末层 norm/输出层不可编辑、纯整张量 rescale 禁**（防变相调温度）；helper 提供 W−αuu^⊤W。
- **配对检验**：编辑前后同题同种子作答，逐题差 d_i 的均值与 SE+turn 错↔对计数——模型自检的基本仪器。
- **两协议**：第一=模型自主决定提交；**第二=框架在 300 道保留题（会话不可读不可用）上先检一次（256 题×2 答），模型再答 SUBMIT 或 WITHDRAW**，撤回不评测；第二协议还封了 Python 会话（仅工作目录+框架接口）。
- **损坏副本任务**：MLP 输出矩阵 8 连行覆写噪声（λ=200×σ，层 30/64）；编辑器=未损坏的自己，只被告知「有些值坏了」，不给干净参照（文件访问第一协议未封锁——见金子⑤审计）。
- **Keel 四件套**：failure census（512 题普查：精度/cut 份额/cut 中循环份额/完成答案精度）→**repair objective**（「明显降 cut 份额+精度不显著降」，理由见金子①）→editing harness（视觉仪器：可贴失败图、注意力落图分布、灰图对照读数）→**多 editor 独立运行+held-out 选择**（1,000 题保留集配对，过修复检验=降 cut >2SE 且精度差为正；不交叠张量的最优两编辑可并集再评）。Editor=GPT-6 Astra 最大推理档（API），预算 40 前向，会话至 260 回合/14 小时。

## 3 主结果核验（两文主表全量对表）
### 3.1 LM-Rewrite（Tab. 2/8/10/13）
- **规模阶梯（Tab. 2，四档全量）**：2B 不编辑（held-out 9.0/损坏副本 0.0/无编辑）；4B own 44.1→0.0（自伤、终盘撤回）、损坏副本 0.0→0.0；9B own 47.5→0.0、损坏 0.0→0.0（**定位栏：4B 指 layer 21〔真伤在 15〕、9B 从不点名矩阵**）；**27B own 22.4→29.6（+7.3*）、held-out 57.2→58.3（+1.1*）、损坏副本 0.0→33.0***（base 58.5）。
- **第二协议 8 会话全披露（Tab. 13）**：5 撤回（3 次无编辑可留+2 次检验后撤）+3 提交——session 1：check +2.5→**held-out +0.5（57.8%，p=0.25 不显著）**；session 2：check +6.6→**held-out 61.3%，+4.0* [2.3, 5.7]**；session 8：check +2.5→**held-out 63.8%，+6.6* [5.0, 8.1]**——摘要「+6.6 未见题」坐实且**有 CI**。**「八连会话只升」的构造注记**：撤回=保持现状（编辑不替换），所以模型在用版本单调不降——其中只有 2 个会话的编辑显著为正。
- **最大增益的编辑形态**：+6.6 来自**全体 48 个线性注意力层 time-step bias +0.5**（一个均匀标量改动）——不是精密方向工程。
- **修复细节（E.3）**：定位统计=每矩阵最大权重/中位数——损坏矩阵 **1397×（其余全部 ≤162.3×）**；修复=超 15×中位数裁剪（20 矩阵共 158,399 权重=**0.013%**）；**因果消融干净**：只改它点名的矩阵→**55.0%**（110/200）、只改另外 19 个→**0.0%**；**修复值不是原值**（cosine 0.002=随机水平、行范数 825→39.7 vs 原 3.85）。
- **图像迁移（E.6）**：修复只在文本数学上找到测试，六图像基准（MMStar/HallusionBench/POPE/ScreenSpot-v2/MathVista/MathVerse）pooled 恢复 **83% of base**；ScreenSpot-v2 **0%→89%**（base 93%）。**口径注记：文本 held-out 修复=33.0/58.5≈56% of base；摘要「80%+」指图像基准 pooled**。
### 3.2 Keel（Tab. 1/6）
- **census（Tab. 6，512 题普查）**：0.8B thinking：精度 34.2/cut **46.9%**/cut 中 **84.6%** 是循环/完成答案精度 64.3；2B：62.1/29.3%/70.7%/87.8——**「失血全在循环、完成即大多对」**。
- **主表（Tab. 1）**：0.8B：thinking 48.2→Keel **56.1（+7.9，起点=博客 prior edit）**，超 prior edit+BF（55.5）/prior edit（55.0）/预算 forcing（53.5）/presence penalty（52.7）/directional ablation（52.9）/reflection suppression（52.4）；2B：thinking 65.2→Keel **72.3（+7.1，†显著超全部基线）**。**12/12 分基准全正**；2B directional ablation 一个编辑都没保留（自家精度检验全不过）。
- **GUI grounding 迁移**：两模型 GUI grounding 增益最大（0.8B ScreenSpot 22.2→36.4；2B 59.4→78.1）而 **practice 池（ViRL39K 几何/图表/科学/空间）不含 GUI/对象探测题**——编辑作用于故障不作用于题型。
- **成本（C.9/A.4）**：每模型 3（0.8B）/4（2B）次编辑运行×7.6-11.8 小时+单 GPU 分摊前向；editor 每次会话 ~104 回合/40 前向/3.9M 输入 token（多为缓存）/168k 输出——**成本结构=API 前沿模型数小时+少量 GPU**。

## 4 深读金子（摘要外）
- **金子①「反馈信号选择=找移动噪声最多的可观测」（Keel §2.3 原文逻辑）**：编辑预算内几点精度的真实增益与 SE 同量级、不可辨；**循环份额一动就是好几个 SE**——所以把任务从「提精度」改成「修被诊断的失败」。这是「换可测反馈面」的第三样本（连 Piccolo 金子② loss↔精度脱钩/#105 AdaObs 观测面/#99 判别任务别用 loss 当反馈）——**姊妹库口径：反馈面选择优先看信噪比，不看信号是否「直接」对准终极指标**。
- **金子② 规模差的本质（#102 附录 A 原话）**："What scale adds, in these sessions, is **the experiment around the edit rather than the edit itself**"——**9B 的代码在循环里打印过每矩阵离散度（损坏矩阵 0.0985，其他 ≤0.0124）而模型没有评论它**（E.3 原文"the model does not remark on it"）——信号可见、选择器不用：**#103「proposer 写得出、selector 认不出」的微观标本**；4B/9B 靠加噪声试错，27B 先读隐藏态再沿测得方向编辑。
- **金子③ 修复≠复原**：修复行的值与原值 cosine 0.002（=随机）、范数 39.7（原 3.85/坏 825）；named-matrix-alone 55.0%——**修的是功能不是参数**：模型给自己的副本写了一套新值，功能回来了。「像断了骨自己长好，不是装回原骨」。
- **金子④ check↔held-out 脱钩（session 1）**：框架检验 +2.5、held-out +0.5 不显著——**保留集检验也不是 held-out 的保证**（检验集 256 题在 4,096 token 预算、评测 490 题×8 答在 16,384 token）——连 #103/#91：selection 瓶颈在任何一层检验都可能出现。
- **金子⑤ 越权审计（E.3「What the models' code read」）**：第一协议文件访问未封锁，作者**逐行审了 573 次代码运行**：9 个会话无一读权重文件/损坏文件/held-out 题（2B 导入过框架模块+建了空目录）——**权限开放下的行为规训数据点**（安全侧：给能力不等于用能力；8/9 完全守界）。
- **金子⑥ 仪器与任务框架是必要条件（Keel 消融）**：去掉视觉仪器→text-only editor 的编辑**不过修复检验、不保留**（模型保住全部循环）；去掉 census+repair objective→editor 大多**不提交任何编辑**（D.3）——「只按精度判断的 editor 会瘫痪」=金子①的消融版。
- **金子⑦ 跨 editor 收敛+因果检验（Keel §3.4）**：独立 editor 在两模型上**都改中层 attention 输出投影**（0.8B Keel 编辑=layers 8-22 注意力/线性注意力输出按半强度移除每层一个方向；2B=两个全注意力层 4 个 head 反射方向/第三层单 head 增强）；因果三连：移除更强→循环更少、放大→循环更多、**同范数正交方向→复现不出削减**；**循环中模型不再看图**（blank-image reads：image advantage 随思考变长衰减至零）——「循环=中层注意力输出驱动的内部自锁」是可重复定位的机制。
- **金子⑧ 编辑器适应起点权重（D.6）**：在博客 prior edit 上跑第二轮，目标自动从「循环」换成「仍被截断的答案」，改 MLP down_proj（layers 15/17-20，含 prior edit 改过的两层）——**不是固定配方，是对当前权重的诊断**（编辑可叠加：D.5 六个数字的再编辑又显著提升）。
- **金子⑨（LM-Rewrite 撤回纪律）**：第二协议 8 会话撤 5 次——**「提交前检验+敢撤」把权重自改从赌博变成工程**（连 #53 撤走检验/#68 乱进化的反设计）；第一协议 27B 的首个会话也主动撤回过一个不达标的编辑（E.7）。

## 5 库内连线
- **#103 Resolution**：金子②（9B 信号可见未用）+金子④（check↔held-out 脱钩）=验证器瓶颈在权重自改域的两个微观标本。
- **#99 Piccolo 金子②/#105 AdaObs**：金子①信号选择=「反馈面」家族第三成员（loss 脱钩/观测面进化/失败信号优先）。
- **#91 PACE**：Keel 的 held-out 选择+>2SE 修复检验=acceptor 统计纪律族；#102 第二协议的保留集检验同族（且金子④给出该纪律的边界）。
- **#68 乱进化破坏**：小模型自伤（4B/9B break themselves）+金子⑨撤回纪律=权重层防破坏的工程答案。
- **回流轴三条路（#93 蒸馏/#101 内化/本线编辑）**：本线=非梯度非训练直接改权重——与 #101 BaseRSI 合看构成「harness/权重增益回写」的三种通道。
- **#66 约束产生可迁移性**：两文都是**极小改动面**（0.013% 权重/每层一方向/一个标量偏置）+跨基准迁移（文本→六图像基准；无 GUI 题→GUI 最大增益）——支持「修改空间小→可迁移」；HookEvo（#120）宽编辑胜的矛盾待其深读后裁决。
- **#37/#51**：Keel census「完成即大多对、失血在循环」=诊断式评测观（聚合分掩盖失败结构）。
- **#145 Safe Personal RSI**：金子⑤越权审计+「编辑当 commit 可读可回滚」（#102 结论原文）=RSI 安全侧在权重层的对应物。

## 6 诚实边界
**共同**：单模型家族（Qwen3.5）；无 venue（v2/v1 一周内）；无 repo/编辑工件释放声明；增益绝对值小（+6.6=57.2→63.8 级）。**#102**：单任务域（DeepScaleR 数学文本）；**损坏是作者自置**（已知存在单因解——比自然失败容易，作者附录 A 自辩「两问分离」）；「八连只升」部分是构造使然（撤回=不变）；图像修复 83% 是六基准 pooled 相对值（文本 56%）；编辑器=未损坏的 27B 自己（诊断能力来自完好大脑——不是「坏掉的自医」，是「医生自医自己健康的知识」）；2B→27B 间涌现阈值未定位（四档粒度）。**#107**：单失败类型（循环）；0.8B/2B 小模型；editor=API 前沿模型（黑盒依赖+成本不可复算）；GUI 增益虽最大但 ScreenSpot 绝对值仍低（0.8B 36.4）。

## 7 遗留（深读新设）
- Takehi 博客（Sparks of Weight-Space Programming）是否入库（权重自改线的库外起点、两文共同依赖）。
- 编辑工件/代码若释放→第三方复算窗口（27B 家族开源使复算可行）。
- 9B「打印而未察」的机制层追问（什么让 27B 用了同一打印流里的信号——连 #103/#105 的观测面问题）。
- 涌现阈值定位（9B↔27B 之间）与跨家族验证（Llama/GLM 系）。
- Keel 编辑对新任务/分布漂移的耐久性；编辑间的相互作用（D.5 已开「再编辑」首例）。

## 8 裁定
- **#102 T2 [高价值] 维持（深读坐实）**。加分：配对检验+评测**先固定**（准则 6 顶格形态）+573 次代码运行越权审计+因果消融（named-matrix-alone 55% vs 其他 0%）+8 会话全披露含不显著者+修复值非原值的诚实核验（cosine 0.002 主动报告）。不加 T1：单家族/单域/增益小/无第三方复算/无 venue/无工件释放。
- **#107 T2 维持（深读坐实，合并读后注「与 #102 同线互证」）**。加分：held-out 选择纪律+设计级消融（金子⑥）+因果三连+跨 editor 收敛+GUI 迁移+诚实负读数（2B directional ablation 全灭、无 census 的 editor 瘫痪）。不加 T1：API editor 黑盒、小模型、单失败类型、无 venue、成本不可复算。
- **线级裁定**：权重自改线三站（博客→Keel→LM-Rewrite）=L1 层当周最热判断深读坐实；**「免训练改权重」与「训练改权重」的边界被推薄**——编辑一次成本（数小时+单 GPU）已可与一次小 SFT 竞争（连 #112 三路对照）。升级触发器：编辑工件释放+第三方复算；跨家族复现；venue；修复任务从「自置损坏」升级到自然失败。
