# RSI 全景图与核心未解决问题

> 本库的领域地图：先定义（什么是 RSI、什么不是），再分层给证据强度，最后列未解决问题。建库版（2026-11-16），随深读滚动修订。

## 一、定义与判定纪律

**RSI = 系统把"改进自身性能的手段"作为产出，且改进闭环中至少一环由该系统自身完成。**

三条判定纪律（防概念膨胀——本领域最常见的引用污染是把"任何自动化"都叫 RSI）：

1. **闭环性**：必须存在"生成→评估→再生成"的闭环；单向流水线（训一次就完）不算。
2. **自指涉深度**：区分改"外挂"（工具、prompt、数据）与改"自己"（权重、代码、研究流程）——深度是分级轴，不是二元判定。
3. **可审计性**（准则6）：自改进声明须有 held-out 评测 / 外部 verifier / 版本存档可 diff。"agent 说自己变好了"不算证据。

**不属于 RSI（但常被混入）**：纯蒸馏、普通 RLHF（人类在环反馈）、静态 NAS 一次性搜索、test-time scaling（推理时算力换性能，无闭环）。

## 三、核心未解决问题

1. **自改进 scaling law 不存在**（本库头号问题）：迭代自改进的收益随迭代次数/规模如何变化？没有任何工作给出跨迭代的定量规律。复利派证据（#02 三轮迭代同升、#06 代际提升、**#37 两轮内 8/10 模型偏好持续提升**）与收敛派证据（#04 collapse、#03 反例、NAS 平台期、**#37 第二轮 benchmark 侧增益微弱**）在同一层内并存，无统一模型。**#52 CUA-Master 新增第三立场（2026-11，受控对照）**：纯自生成闭环（self-policy 注释器）增益有限、分布自锁——但**外部开放世界知识注入+模型弱项引导的混合闭环跨迭代持续增益**（3 轮 SFT+RL 各阶段分工：SFT 吃饱后 RL 再 +15 点）。含义：复利与否可能取决于**燃料来源**（自生成 vs 4. **长时程能力**：#20 显示 32h 级任务 AI 仍大幅落后——但 #07 显示时长每 7 个月翻倍。两条线何时交叉？交叉点=自动化研究实质性起飞（#29 的核心假设）。需要持续盯 METR 后续修订的曲率讨论。**#37 补充数据点：144 小时窗口内的全自主后训练（选数据→训→选 checkpoint）已由 10 个 agent 全部完成——训练环节先于研究环节被吃掉。**#57 CLE 补充（2026-11）：长时程的另一半不是"单任务时长"而是"跨任务经验复利"——600 级进阶梯上最好系统仅 23.3% 全通关、反馈修订中位 +5.3pp：**经验积累这一半在真实工作流上还远未解决**。**#57 深读补注（2026-11-17）**：经验复利的「测量仪器」本身到位（双门审+隔离评分+评测器 96.86% 人机一致+三重跑 99.46%），缺的是归因实验（reset-harness 对照）——「跨任务保留知识值多少分」是 Q1/Q4 共同的下一个可跑实验；其 T1-T5 学习自主性分层（guided→self-driven）与我库 L1-L4 证据层轴正交，可作 Q4 的第二坐标。**
