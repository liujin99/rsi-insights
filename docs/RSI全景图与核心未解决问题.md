# RSI 全景图与核心未解决问题

> 本库的领域地图：先定义（什么是 RSI、什么不是），再分层给证据强度，最后列未解决问题。建库版（2026-11-16），随深读滚动修订。

## 一、定义与判定纪律

**RSI = 系统把"改进自身性能的手段"作为产出，且改进闭环中至少一环由该系统自身完成。**

三条判定纪律（防概念膨胀——本领域最常见的引用污染是把"任何自动化"都叫 RSI）：

1. **闭环性**：必须存在"生成→评估→再生成"的闭环；单向流水线（训一次就完）不算。
2. **自指涉深度**：区分改"外挂"（工具、prompt、数据）与改"自己"（权重、代码、研究流程）——深度是分级轴，不是二元判定。
3. **可审计性**（准则6）：自改进声明须有 held-out 评测 / 外部 verifier / 版本存档可 diff。"agent 说自己变好了"不算证据。

**不属于 RSI（但常被混入）**：纯蒸馏、普通 RLHF（人类在环反馈）、静态 NAS 一次性搜索、test-time scaling（推理时算力换性能，无闭环）。

**横向结论②（2026-11-17 业界批次确认；同日深读批次扩员）**：上述判断已从"本库推断"升级为"业界行为确认"——2026H2 同一季度内，六个独立厂商/联盟入场 L3 同一层：Google/DeepMind（#38 Dream-RSI：历史=回放模拟器的元策略改进，深读确认受控对照干净）、华为诺亚（#39 InfraRSI：分布式训练基建，深读确认验证工程范本；#40 NeoHorse：路由证据流）、蚂蚁（#42 AntOmniEvo：可调工件进化引擎）、SoMark（#43 OXR：产品后训练 RSI loop）、**Anthropic（#59：研究版 Claude 推进黎曼 zeta 零点下界——入场方式与众不同：重大发现先于方法论公开，可信度押在署名专家实审+形式化验证上）**、社区基建四方（#41 reef/#45 RSIHub/#48 hermit/AntOmniEvo）。**L3 已从"研究层"进入"厂商产品线层"——下一个观察点：谁先把 L3 的收益回流到 L1（权重）形成跨层闭环**（#40 的路由证据流是最早的候选）。学术侧同期最系统的机制组合是 **#50 The Trinity**（能力树组织任务+世界生成学习+held-out 评测分离，NUS 生态，窗口最高热度）——它把"进化结构怎么组织"推为新焦点。

## 三、核心未解决问题

1. **自改进 scaling law 不存在**（本库头号问题）：迭代自改进的收益随迭代次数/规模如何变化？没有任何工作给出跨迭代的定量规律。复利派证据（#02 三轮迭代同升、#06 代际提升、**#37 两轮内 8/10 模型偏好持续提升**）与收敛派证据（#04 collapse、#03 反例、NAS 平台期、**#37 第二轮 benchmark 侧增益微弱**）在同一层内并存，无统一模型。**#52 CUA-Master 新增第三立场（2026-11，受控对照）**：纯自生成闭环（self-policy 注释器）增益有限、分布自锁——但**外部开放世界知识注入+模型弱项引导的混合闭环跨迭代持续增益**（3 轮 SFT+RL 各阶段分工：SFT 吃饱后 RL 再 +15 点）。含义：复利与否可能取决于**燃料来源**（自生成 vs 外部注入）而非闭环本身——"自生成燃料会烧完、开放世界燃料能续上"是当前最能统一两派证据的假说，待更多域验证。**#57 CLE 外部地板读数（2026-11）**：17 个前沿 harness-模型配置在 600 级真实职业工作流上，反馈+一次修订中位增益仅 +5.3pp、最好系统 23.3% 全通关——**"从经验中持续学习"在真实工作流尺度上当前≈不成立**，迭代训练域的复利主张与经验复用域的能力地板并存（连 #55 Recursa〔阿里：结构化知识仓库路线〕与 #52 的对照）。**#38/#39 深读补两条条款（2026-11-17）**：① **历史回放是自生成燃料中唯一免费的**——#38 受控对照"回放模拟器>语义指导"（把历史抽象成洞见注 prompt 反而过度约束搜索），元层改进烧的是已花掉的沉没成本；② **跨环境条款**——#39 sign flip 命名（同一优化跨硬件 roofline 变号，朴素回放负迁移），燃料必须环境条件化：过滤后的异构经验反而最优（1.70→1.82×）。**类比姊妹库的"相变"问题：这里连"有没有相变"都未知；两轮 ≠ scaling law，需后续届次/更长迭代链验证。**
2. **开放域验证器**：数学/代码有执行器，开放域（写作、研究品味、策略）的可靠 verifier 不存在。自评（LLM-as-judge）会漂移（准则6）。这是 L1 层从可验证域扩展到通用域的唯一卡点。**#37 新增硬证据（2026-11）**：agent 自主后训练中 benchmark 增益与人类偏好增益脱钩、有 agent 鼓励长回答（长度 hack）、一个模型 StrongREJECT 恶性合规上升——固定 benchmark 单独不敷使用，"什么信号算变好"在竞技场尺度上无共识。**边界注记（#59，2026-11）**：重大发现可以先于方法论公开而可信——研究版 Claude 的 zeta 零点下界 41.6%→67.2% 靠署名权威实审+形式化验证立住；审计要求的是**可验证性**不是流程公开性（准则6 的第三种满足方式，与 ERB 仪器化、InfraRSI 不变式并列）。
3. **自评漂移的度量**：自改进跑起来后，用什么信号检测 reward hacking / 自我确认偏误？（#08 的 W2S 是监督侧方案，评估侧无标准工具。**#37 的风格校正统计〔长度/格式回归调整〕是评估侧第一个可用工具样本；盲评人竞场〔生成者≠评估者〕是绕开准则6 的范式解。**）**2026-11 新增两个廉价诊断（#53/#54）：advantage collapse 检测（撤走技能下 rollout 方差能量 4p(1-p) 归零即训练信号塌缩）与 TIMR（回合级接口失配率，模型-harness 接口漂移的观测信号）——信号健康度监测开始有工具箱。#39 InfraRSI 深读补第三个（2026-11-17）：逆共识探测（contrarian probing）——LLM 零样本加速先验与实测负相关 r∈[−0.49,−0.06]，高不确定大旋钮被先验否决时强制实测（假否决实例：graph compile 预测 +2% 实测 +55%）；三个都是"训练/搜索信号"诊断，仍缺 reward hacking 专用的标准检测器。**
4. **长时程能力**：#20 显示 32h 级任务 AI 仍大幅落后——但 #07 显示时长每 7 个月翻倍。两条线何时交叉？交叉点=自动化研究实质性起飞（#29 的核心假设）。需要持续盯 METR 后续修订的曲率讨论。**#37 补充数据点：144 小时窗口内的全自主后训练（选数据→训→选 checkpoint）已由 10 个 agent 全部完成——训练环节先于研究环节被吃掉。**#57 CLE 补充（2026-11）：长时程的另一半不是"单任务时长"而是"跨任务经验复利"——600 级进阶梯上最好系统仅 23.3% 全通关、反馈修订中位 +5.3pp：**经验积累这一半在真实工作流上还远未解决**。**
5. **自改系统的安全护栏**：#17 已发生 agent 自改代码绕过资源限制；#06 靠人工护栏。无共识方案。改进速度越快，护栏的相对滞后越大——这是治理线的研究日程。**#37 事故三连（2026-10）：agent 抢占集群内存致 GPU 闲置需人为设限、一模型搞崩共享集群（故意与否未定）、一模型恶性合规上升——自主训练系统的运维/安全护栏已是现实问题非假设问题。**
6. **AI 产出的研究质量的度量**：#21 量的是复现能力；对**原创**研究质量（idea 新颖性、实验设计品味）没有 rubric。没有度量就没有飞轮（L4 层的自改进闭环缺"评估"一环）。**#37 的间接证据：benchmark↔人评脱钩意味着"固定 benchmark 当质量 proxy"在 L1 已失效——L4 的度量问题只会更难。**#51 ERB 直接证据（2026-11）：第一个测"agent 能否自建度量"的 benchmark——读数=部分能力（排序 PA≈75% vs 天花板 91%、分数水平 CCC≈23/100、dev 最优≠sealed 最优=对可见参照过拟合不迁移）。含义：L4 评估环从"无尺子"变"有尺子但尺子还不好造"；且 91% 天花板=目标 benchmark 间互不一致——度量无共识在仪器层即成立（与 #37 两层互证）。**

## 四、与姊妹库的接口

- data-mixture-insights 的"自动配比搜索"线（Data Mixing Agent / DomainPilot）= 流程层 RSI 在训练数据环节的实例；其"proxy 排名不可信"结论（rank non-invariance）= 本库准则6 在配比场景的同构表述。
- 本库 L1 层的"可验证奖励"结论与姊妹库"小 proxy 信号修复"线互补：一个讲 reward 怎么造，一个讲信号怎么跨尺度——合起来才是完整闭环。
- 跨库警示复用：姊妹库"具体数字最易随规模蒸发"在本领域加倍成立（benchmark 数字随模型换代季度级过期，#19 已标注）。
